# 功能登记与生成文档

`capabilities/features.json` 是当前功能及子功能的唯一结构化登记源。`F-001` 等编号标识功能区，`F-001.01` 等编号标识稳定子功能。编号不随名称改变而复用；需求、代码路径、测试目标、入口、限制、依赖、版本、Issue/PR 和验收证据在同一记录关联。

每项独立记录实现状态、软件验证、真实模型验证和部署状态。已实现不代表测试通过；历史有限的软件基线、当前新增验证与真实模型证据分别登记。`local_only` 不授予公网部署资格，源码或测试文件存在也不自动授予通过结论。历史记录仍是外部私有材料，没有复制用户原片或私人数据库到仓库。

`scripts/features.py` 只读取登记与仓库文件，不访问应用数据库、模型、凭据或 GitHub。执行 `python scripts/features.py` 生成 README 状态区块、功能总表、验收指南、分阶段交付计划和公开路线图。`--check` 验证编号、依赖无环、代码/测试路径、证据引用/范围、各状态约束以及生成文件是否漂移。错误登记或未同步视图导致非零退出；该检查不执行应用验收，也不能代替独立审核。

验证证据按功能范围引用。真实模型通过必须具有 `live_model` 证据；公网通过必须具有 `deployment` 证据和可公开的 HTTPS 地址，拒绝回环、私有地址和本地域名。登记自检仅用于登记与来源说明，不能资格升级应用软件。登记工具本身没有权限改变部署、模型资格或历史报告。

目前身份/空间和本机测试账号已进入部分交付。登记的14类业务根资源及明确嵌套/历史文件路径已通过161项矩阵、58项实际双会话浏览器检查，独立38项补测分别记录；完整收费执行隔离、正式账号切换及真实供应商账单仍未验收。离线迁移工具完成原数据私有副本演练，预算按项目独立管理，工作空间没有总上限；各轮历史证据保留但不累加覆盖。社区研发与公网平台尚未交付。A独立审核只对应报告记录的当时登记/生成器hash，不自动覆盖后续B/C变化。各阶段门槛见[分阶段计划](/docs/plans/platform-delivery/)，当前逐项事实见[功能总表](/docs/reference/feature-catalog/)。

后续模型费用基础的范围另记于 `capabilities/model-accounting-validation.json`：109项相关测试包含在405项回归内、22项实际浏览器检查通过；独立109重跑和16补测分别记录。连接版本、通用项目预留、人工规范化账单及预算待补金额的有限软件结论，不授予所有模型运行时接线、真实供应商认证或收费执行资格。F-001.04、F-009.03继续部分实现，软件整项仍未验收；功能数量不因基础模块通过而提升。

后续项目执行接线另记于 `capabilities/model-runtime-validation.json`：139相关包含于435项选定测试、42项浏览器通过；独立首跑、修复后受影响重跑、补测及实际worker检查分开记录。真实账单、全部收费执行、模型/成片/公网资格不提升。仅覆盖顺序文本、文本测试和单张图片的单独SQLite软件行为；两个整体功能仍部分实现。
