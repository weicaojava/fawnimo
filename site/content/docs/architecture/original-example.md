# 原创可导出示例

项目大厅提供两种入口。文字示例保留 `POST /api/v1/identity/demo` 的原始 v1 模板：7个待确认镜头与21条提示词。`POST /api/v1/identity/demo-exportable` 另建包含原创素材、剧本准备、镜头计划、明确采用和剪辑草稿的工程。两者都保留旧工程，使用同一个每空间20次新请求上限；原请求恢复不新增名额，同一标识换用另一模板返回409。项目费用预算仍按项目设置。

## 身份与私有执行边界

公开输入只有 `request_key`。网关从会话取得真实用户与空间，核对当前成员的 owner/editor 权限，先保存控制请求，再联系该空间的固定 worker。浏览器不能提交工程ID、素材、工具路径、费用或质量资格。

内部 RPC 为 `/__workspace/original-example`，位于通用 `/api/v1` 代理之外，不进入公开 OpenAPI。它检查唯一的私有 token、固定空间、可信用户与成员角色；旧独立本地入口没有固定空间时拒绝执行。控制请求已经成功时，只读回查 worker 的原结果；内容缺失时不重新渲染。普通首次请求与未知结果恢复也先回查已有完成记录。

模板版本、空间、用户和原请求共同派生新工程与章节身份。请求记录先保留这些尚不存在的目标；实际安装时再次要求目标不存在。已有目标或子资源身份冲突会使整笔安装回滚，不认领旧内容。

## 原创媒体与文件发布

`demo_media_child.py` 使用本项目编写的几何绘制代码与 PyAV，在一个受控根进程内编码7段视频并保存7张PNG。每段4秒、360×640、12fps，无源声音。没有输入用户素材、字体、纹理、数据库或模型配置；作品源码按仓库 Apache-2.0 许可提供。原上游代码来源仍由仓库致谢与许可说明记录。

子进程使用环境变量白名单、有限输入、固定画面参数及超时。编码在根进程内完成，不另起编码器后代。Windows Job 的活动进程数不能作为所有后代文件I/O结束的保证；本示例在根进程退出并完成等待后才验证、发布文件。

父进程在数据库写锁外核对完整字节、SHA256、PNG解码以及MP4实际画面时钟。完整私有尝试文件通过同一文件系统的独占硬链接发布，最终名称绑定原请求、媒体位置与内容hash。相同画面的PNG也保留独立的媒体位置。已有最终文件须匹配原字节，不修复或覆盖；失败或取消保留私有尝试文件，旧执行器不会删除后来成功的素材。

## 一次安装与恢复记录

每个 worker 同时只处理一个示例制作请求，忙时返回429且不消耗另一次 worker 尝试。同一请求最多3次本地尝试，使用整数计数、有限租约与条件更新。渲染、探测和文件hash均在写事务外进行。

最终一个新的 `BEGIN IMMEDIATE` 事务检查当前归属和租约，创建工程、章节、7个镜头及细节、14份媒体、独立角色/场景及版本、经过正常校验的剧本快照、未绑定模型的计划、7份导入采用及来源、剪辑草稿与完成记录。既有服务中的事务内校验和写入逻辑被复用，不嵌套会自行提交的服务包装。写锁内只复核之前证明的文件身份与元数据，不重新hash或编码。

旧场景库要求名称全局唯一，新示例在同一写事务中选择尚未占用的可读名称，并新建场景身份；不会把另一个工程的同名场景当成自己的素材。

`local_example_requests` 保存固定请求和尝试归属。`local_example_ready`、`local_example_media`、`local_example_takes` 使用独立列与实际外键保留剧本、计划、草稿、14份媒体和7份采用。SQLite约束与触发器限制首次状态、整数尝试、租约转换、真实上下文、完整引用和不可改删/替换的完成历史。完成状态与所有新业务数据在同一事务提交；失败不会提交部分工程。

控制层和 worker 都在完成提交及会话清理后保留本次认领见证。取消即使隐藏了提交后的返回值，也只能释放自己已经认领的token。多个任务收尾使用 `gather(return_exceptions=True)` 后再受保护地等待：子任务的有意取消被作为结果消费，调用者的取消在全部收尾后继续传播。最终提交已经成功但响应丢失时，后续同请求读取原完成记录。

完成请求回放检查原始不可变来源、归属和素材字节；用户后来修改标题、计划选择或当前采用不会被重置。原文件已丢失、改变或归属不符时返回冲突，不自动补素材或重建工程。

## 剪辑与资格

新示例的镜头 `status=ready` 表示预置事实已填写并完成准备，仍不表示模型生成状态。计划使用固定的本地示例意向，编译时不提供模型运行配置，`binding=None`。既有提交门禁对这种历史计划始终给出 `model_unbound`，后来配置同名模型也不会激活旧计划。

素材明确记为原创示例的 `user_import` 来源，没有伪造模型任务或费用。剪辑草稿的7条剧情保留标记初始全部未确认。用户逐条检查、保存并锁定版本后，使用既有本地导出任务生成360×640/30fps MP4、SRT、VTT和ZIP。原素材无对白，字幕为空或仅有格式头；导出音轨为静音，不表示配音或音乐制作。

前端使用 generated client，并分别保存文字/可导出示例的恢复标识。异步完成必须仍属于原页面与身份范围，清除标识和跳转前再次检查当前会话，防止另一标签页换账号后使用旧响应。示例功能的软件状态见[功能总表](/docs/reference/feature-catalog/)。它不授予真实模型、语义、口型、配音、完整成片或公网部署资格。

操作步骤见[原创示例体验](/docs/guide/original-example/)。后续平台工作见[分阶段计划](/docs/plans/platform-delivery/)。
