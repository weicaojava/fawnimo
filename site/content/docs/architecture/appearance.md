# 界面主题与工作台外观

全站采用用户选定的 A 电影控制室风格。亮色使用中性浅灰背景、白色面板、深色文字和少量冷蓝强调；暗色使用蓝黑背景、分层面板和浅蓝操作色。媒体预览区在两种主题下保持暗色。

用户于 2026-10-28 确认本版设计。根目录 `design.md` 将 A 方案与改进后的亮色主题固定为全站视觉规范，现有页面及新增页面共用同一套颜色、排版、表面层次和控件规则。

`front/src/styles/tokens.css` 定义颜色、字体、间距和基础尺寸。`base.css` 提供焦点、文字溢出和减少动态效果规则，`studio.css` 管理全局导航、共享控件和弹层。页面专属样式限于项目、生产和素材管理三个范围。

主题由 `useThemeStore` 统一管理。页面加载前读取 `jellyfish_theme`，未选择时跟随系统；用户选择后保存在当前浏览器。顶部主题按钮与设置页使用同一状态，其他标签页的主题修改同步生效。浏览器禁用存储时仍可在当前会话切换主题。

Ant Design 普通组件和静态消息、确认弹窗通过同一组主题参数配置。已有 Tailwind 颜色类在配置中映射至语义颜色，避免未改写的局部界面沿用另一套配色。手机端使用导航抽屉，模型与供应商首次打开默认使用卡片，可手动切换列表；表格和生产区域保留各自滚动容器。

本次外观改造保留现有业务路由、接口、输入字段、交互入口、告知文案和验收钩子。分镜编辑继续负责准备与确认，分镜工作室继续负责生成，任务中心继续只呈现通用任务状态。界面主题不会改变模型配置、产生模型调用或改变既有业务验收结论。

验证记录单独保存在工作区 `outputs/hallmark/`，使用隔离复制数据库；历史阶段验收数据和报告不变。
