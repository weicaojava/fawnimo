# 模型费用与账单

模型费用基础复用单个项目的 `execution_budgets` / `execution_budget_entries`，没有工作空间总上限。当前仅支持 SQLite。文本工作流、连接测试、图片、视频视觉理解、ASR 的通用账目与账单服务已实现；这些运行时尚未接入该准入服务，身份网关的收费门禁仍关闭。持久视频继续使用现有独立准入，不自动取得通用账单关联。

## 连接与报价

`provider_connection_versions` 在实际供应商新增、修改、删除事务内单调推进，无旧记录的连接视为版本0。删除后保留版本墓碑，同ID重建不会重新匹配旧任务。SQLite触发器同时拒绝回退、删除和替换时钟。文本/图像执行在同一查询中读取模型、供应商、版本和临时密钥；版本进入安全绑定，密钥仅用于该次内存调用。已排队旧绑定遇到连接变化时失败，不改向新凭据。

受信 `ModelPriceConfiguration` 默认关闭。规则显式指定调用类型、模型、供应商连接版本、账户版本、人民币单次费用上界及依据；未知、零价、冲突、过大或带未知字段的配置不通过。`ModelPriceRegistry` 仅解析服务器文件，尚未接入启动参数或执行运行时。网页请求不能自行提供报价获得准入，测试金额不代表真实供应商价格。

## 原子预留与发送证据

`reserve_in_transaction` 供持有 `BEGIN IMMEDIATE` 的服务调用；一次保存1至64个调用的整批清单、可信提交人、项目、报价快照与预留。额度不足会连同同事务任务一起回滚。同范围键与完全相同清单重放复用旧记录，换项目、操作者或报价会冲突。另一项目的额度不被占用。

每个 `ModelCallCharge` 固定调用与历史连接身份。`prepare_call` 只允许一次CAS取得发送许可，并先将预留标为费用未知；未知结果、取消意图、就绪输出和缺少账单都不能退款。响应请求标识只是接收证据，不是实际费用。只有仍未发送的 `planned` 单位可以释放。批次、调用身份及账单证据的保护同时覆盖更新、删除和 SQLite `REPLACE` 的主键/自然唯一键冲突。

## 人工账单核对

离线工具保存私有原始文件与规范化CSV，数据库记录两份证据的哈希、明确供应商/连接/账户版本及操作人。不自动认证供应商，不根据生成内容、usage、任务失败或账单缺行猜金额。

一行必须精确匹配一个历史账户和保存的供应商请求标识。缺失或多义匹配保留未知预留；每次调用、每个账单行仅有一个最终收据。同一来源键重复导入复用原记录，改变原证据或金额不能覆盖历史。只有明确 `not_charged` 且金额0的匹配行可释放；`charged` 金额0仍作为显式已结算记录。

实际账单超过原报价时保留全额：已有授权余量足够，则原预留结算到原报价，额外部分写入独立差额记录，收据同时绑定两部分；不足则保留全额账单和原未知预留，暂停该项目新调用，等待所有者显式补足上限后重新核对。原报价指纹被标为超界，换一条仍低于已观察金额的报价也不能绕过。

规范化金额表示单个请求的总费用。多份重叠未决证据按调用取最高观察总额，扣除该调用已结算全额或仍持有的预留，避免重复占额度；所有行和争议历史仍保留。已核对调用再次出现账单行会产生冲突。只有账户、请求、收费状态、币种、金额完全一致，且明确引用原收据的人工决定，才可确认“重复证据”。决定不可改删，不新记费用。不同金额更正、退款与多义请求目前保持未决，未提供隐式合并或差额冲销。

## 私有维护边界

`reconcile_model_billing.py` 要求已存在的有效所有者、固定空间标记、网关根锁和工作进程锁。未完成认领的持久迁移日志也会阻止导入，避免破坏中断恢复。账单文件位于固定空间 `files/billing-evidence/`，不注册为素材，不可从素材列表/下载接口读取；路径跳转和覆盖不同字节均拒绝。现有完整files离线备份包含这些文件，因此备份也应保持私有。

预算API的账单总额、观察金额、待补金额与计入账单后的余额使用精确十进制字符串；流式Python整数汇总避免大额证据导致SQL聚合溢出。读快照使并发核对不能拼接旧账单与新余额。

本地自作账单、HTTP夹具、进程及浏览器检查只验证上述软件行为。真实供应商账单认证、所有模型运行时接线、全收费执行隔离、模型质量、完整成片和公网资格仍独立待验。F-001.04、F-009.03继续为部分实现。
