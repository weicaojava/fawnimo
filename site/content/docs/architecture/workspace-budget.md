# 工作空间视频预算

身份网关的每个固定空间 worker 使用自身数据库。`workspace_budget` 保存单一人民币累计上限和修订号，首次初始化上限为零；`workspace_budget_changes` 保存操作者、原上限、新上限和修订收据，禁止改删。初始化先绑定空数据库的空间身份，再安装预算保护，不能通过预算初始化认领旧业务数据。已有非零余额但没有空间上限的数据库拒绝自动迁移。

空间已预留、已结算金额直接汇总本数据库的 `execution_budgets`，不维护另一份可漂移的余额。工程预算可以各自设置不同上限，但每笔持久视频任务同时受工程和空间余额限制。SQLite 写事务内的触发器在工程余额增加时检查空间总额；预留超额会回滚任务、任务日志、绑定和额度记录。默认零上限拒绝任何正金额预留。

已有取消、明确拒绝后的恢复、可信实际费用结算均写工程账本，触发器同步保护这些路径。余额改变会增加空间修订号，因此旧页面不能按旧修订覆盖新额度。相同请求恢复不重复预留；接收结果未知继续保留额度，取消意图和生成结果就绪都不能作为费用释放证据。

`GET/PUT /api/v1/video-runtime/workspace-budget` 读取和设置空间上限。网关每次验证当前会话、成员、身份与空间；只有 owner 可以修改。worker 再检查网关注入的角色和操作者，客户端请求头不能覆盖这些可信字段。设置上限与不可变操作者收据在同一事务提交，并使用预期修订 CAS；新上限不得低于已经预留与结算之和。

`GET /api/v1/video-runtime/workspace-budget/entries` 返回有界任务标识分页，只包含工程、任务标识、额度状态、预留和结算金额，不含远程身份、提示词、连接凭据或结果 URL。界面位于“系统设置 → 工作空间预算”，所有者可保存上限，其他成员只读；工程预算面板提供对应入口。

当前覆盖范围明确为 `durable_video`。文本 Agent、图片生成和视频理解尚未接入该预算控制，相关收费入口仍由网关拒绝。空间 worker 不继承主机模型凭据，保存正上限也不会启用收费服务。API 的 `provider_bill_verified=false` 保持不变：本机合成金额和任务夹具仅证明软件行为，未取得或核验真实供应商账单，未授予真实模型、成片或公网验收资格。

本轮隔离验证包含跨工程并发、相同请求恢复、事务回滚、未知预留、取消、可信结算、CAS、不可变修改收据、两个独立数据库、HTTP 严格金额、角色及旧标签保护。独立审查另通过真实身份网关到 A/B worker 的保存、越权、隔离及重启检查。功能范围与剩余项统一见[功能登记](/docs/reference/feature-catalog/)。
