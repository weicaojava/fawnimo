---
title: 本机预览资料与离线回退档案
description: 独立预览账号、完整网关根目录备份、新路径恢复和本机反馈。
---

`local_release_data_v1` 提供维护者本机的数据准备与回退档案。`manage_local_release.py` 创建独立 A/B 预览账号，给已停止的身份网关根目录建立一致备份，恢复到新路径并单独记录本机反馈。声明的源码提交用于追溯；实际运行镜像/源码版本、真实独立审核、策略上线、公网与真实用户验收仍各自待验。

维护根目录只保存固定配置、按请求键派生的操作日志、私有账号领取文件和备份档案。预览数据、原稳定数据与恢复目标均位于其外部的独立路径。创建预览时生成两组不同的账号、密码、用户和个人空间，创建全新的身份库，不读取稳定资料，不配置模型，不启动服务。领取文件留在私有维护根目录，普通输出只给出路径。

备份覆盖选定网关根目录的身份库、全部已登记空间数据库、文件、媒体及根目录内连接资料。外部路径引用不会被跟随。维护者应停止该网关和工作进程；控制程序依次取得网关及已登记空间的原生进程锁，活动进程持锁时拒绝新备份。未登记/未完成认领的空间目录需先维护处理。

SQLite 使用只读源连接和 SQLite backup API，包含已提交但尚在 WAL 中的数据。档案逐库核对完整性、外键、所有表行（含自增序列）、结构 SQL 与版本标识；最终复查来源。SQLite 正常 checkpoint 可改写主文件页而不改行/结构，因此逻辑指纹负责数据库一致性；其他文件保持完整 SHA-256/长度核对。只有基础文件确认为 SQLite 时，才跳过其临时 WAL/SHM/journal；普通 `-wal` 结尾的业务文件完整保留。

档案记录所有业务文件的相对路径、长度和摘要；这些是私有资料，可能包含账号、连接与媒体，不进入功能登记、CI 附件或 Git。单次最多 50,000 文件/目录、8 GiB，单文件 2 GiB，SQLite 行值上限 8 MiB、256 表。逐段复制及 SQLite 页进度同时检查增长/容量和 120 秒操作预算；阻塞的操作系统/存储 I/O 不具有硬实时终止保证。仅单机本地磁盘的软件路径已验。

恢复先验证档案清单、每个文件和数据库，再复制到一个全新独立目标。原数据、后来的编辑与现有目标都保留。服务不会通过该入口切换软件版本或启动恢复数据；恢复产物还需按部署计划完成实际切换和任务/连接对账。POSIX 新预览和恢复根目录使用 0700；Windows 使用维护者所选私有目录的 ACL。

操作按原请求键登记并刷盘，目录元数据在支持的平台同步。每次最多一个维护操作；最多 128 操作，其中预览/备份/恢复各 16，本机反馈 64。输入和目的路径绑定原请求；重复请求只恢复历史，保留之后的编辑和账号。进程在复制期间退出会留下原意图与部分新档案/目标，后续读取标为中断，不自动覆盖或重复。进程退出恢复已用真实子进程验证；掉电、磁盘故障、远程共享盘与真实历史生产库切换仍未验。

反馈单独绑定已准备的预览或恢复记录，保留本机意见；它没有认证独立审查/真实用户验收的含义，也不会发送 GitHub 消息。发布、审查、CI、实际部署和反馈各自记录；所有运行版本/CI/独立审查/真实验收/部署权限字段保持未授予。

相关实现与[候选 PR 发布](../community-publication/)、[准确 PR 审查观察](../community-pr-gates/)分别运行。单机维护者、文件系统、原生锁及 SQLite 受信；本入口提供私有数据准备，不承担代码隔离执行或自动上线。
