# Fawnimo 品牌与代码来源

项目英文名称为 **Fawnimo**，中文名称为 **鹿帧**，仓库名为 `fawnimo`。名称由用户在2026年10月29日确认，取小鹿与动画、运动影像的联想。前端标题、导航、登录入口和图标使用新名称，电影工作室A布局和中性亮暗主题保留。

小鹿图标是本项目自作SVG，原Jellyfish图标和历史发布资料作为来源记录保留。现有实现基于[Forget-C/Jellyfish](https://github.com/Forget-C/Jellyfish)继续开发，原许可证、适用版权记录、Git历史和代码来源不因更名改变；见[UPSTREAM.md](../../../../UPSTREAM.md)。

显示名称与数据身份分开。数据库和媒体目录、模型绑定、任务及生成请求标识、浏览器恢复请求key、`jellyfish_*` 偏好键、内部包名继续沿用既有兼容约定。更名不触发数据库迁移、收费调用或新一轮请求提交。

名称确认、GitHub仓库创建、代码推送和公网部署分别记录。名称查询只反映当时公开检索结果，不作为域名已注册或仓库已发布的证明。
