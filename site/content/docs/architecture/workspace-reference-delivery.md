# 固定身份的参考视频交付

身份网关增加显式可选的 `workspace_reference_delivery_v1`。它让已准备的参考视频通过网关送到外部读取方，再交给原空间的固定工作进程核验；不是浏览媒体库的入口。原独立工作室交付协议保留，图片和首尾帧的旧默认指纹保留。当前只支持已有的 Seedance 参考协议和逐镜头锁定计划。

## 交付权限

维护者同时配置准确的 `public_origin` 和相同的 `reference_media_origin` 才会启用。默认不创建交付密钥、此路由返回404。Secure Cookie模式只接受规范HTTPS根origin；纯HTTP仅允许显式本机回环模式，且仍需独立配置的模拟模型运输例外。模型配置中的交付origin必须一致，不能从请求、导入工程或浏览器配置取得替代地址。

私有身份数据根保存32字节 `.reference-delivery.key`，首次独占创建并同步写盘，已有文件不覆盖。启动拒绝重定向、多硬链接、长度错误和变化中的文件；POSIX要求文件本身或整个根目录对其他用户不可访问，Windows由维护者管理目录权限。私有根与前端静态目录必须互不包含，检查发生在身份库或密钥创建之前。离线全根备份包含此密钥，恢复副本仍为私有资料。

网关主密钥按固定空间ID派生独立HMAC密钥。每个工作进程只在私有启动管道收到自身密钥、origin和空间；主密钥、密钥摘要及派生值不进入环境变量、参数、公开档案或API。公开执行档案仅绑定协议版本、空间ID和交付路径。改变交付范围需要重新核对原执行绑定，不能给旧任务悄悄添加能力。

实际链接格式为 `/api/v1/workspace-reference-media/{workspace_id}/{delivery_id}`，查询串含原随机token、整数到期时间和签名。HMAC绑定协议、空间、准确origin、交付ID、token和期限；默认创建后一小时过期，校验使用可信服务端时钟。先校验签名、有限字段和期限，再查询已存在且所有者有效的空间。错空间、未知记录、过期或签名错误统一404，不因来访链接建立空间。

## 固定读取与原费用

只接受GET/HEAD；最多4条并行读取，随既有进程容量配置且限制1–16，繁忙时429。转发目标只取已核对空间的固定回环工作进程，不能提交自选地址。只发送该工作进程的内部凭据和有界Range，不转送来访Cookie、Authorization、身份、角色或内部头。客户端不跟重定向、不使用环境代理，只接收有界MP4及合法范围响应，最多32 MiB；响应结束、断连和取消后共同关闭上游连接并释放名额。

签名不替代工作进程中的原交付记录。原数据库继续检查交付token哈希、原项目/任务/尝试、实际素材证明和文件字节、任务状态、一小时期限及最多16次读取，HEAD也计数。素材改变即拒绝；未知模型调用的原项目费用继续保留，读取和重放不创建另一份模型意图。已就绪工作进程的读取不等待另一个空间的启动锁，同时仍复查身份、配置、迁移锁和死亡进程清理。

网关在认证、路由和服务器访问日志前从请求作用域移除新旧交付查询串，仅在内部转发时使用；所有交付响应加 `Referrer-Policy: no-referrer`。反向代理和远端接收方仍须由维护者管理。完整交付链接属于短期读取凭据，不能公开分享。

## 已验证的范围

本地真实HTTP网关、两个实际固定工作进程和两个自作模型服务使用相同业务ID、不同视频，验证原项目字节、在模型响应前读取、原请求重放、原项目预留、繁忙/范围/断连清理、源变化、16次上限和可信时钟模拟过期。另保留自作错误配置中私有根被静态目录覆盖的反例，并验证启动前拒绝。全根离线备份与新路径恢复核对原密钥；POSIX权限门槛由对应平台回归单独记录。

这不代表真实供应商能够从公网取到素材，也不证明真实账单、模型质量、完整成片或完整收费身份隔离。收费网关仍503，未调用原模型或使用原用户素材。实际运行镜像、生产切换、独立审核和公网部署尚未通过。操作见[维护者配置](../../guide/workspace-reference-delivery/)，参考输入规则见[视频参考输入](../video-reference-inputs/)。
