---
title: 本地模型源码提案
---

`generate_community.py`将明确已prepared的公开需求交给独立配置的本地模型，产生待审Python文字，再通过既有来源检查保存惰性变更bundle。它不执行候选、创建Git分支、推送、创建PR、自批或发布。`execution_authorized`与模型质量、独立审核资格仍为false；生成源码不代表开发已完成。

`maintainer_local_ollama_code_v1`使用独立默认关闭配置，固定数字loopback、准确已安装模型名称/摘要、零外部费用及有限次数，不借用视频项目连接/密钥/预算。协议复用固定`/api/tags`及`/api/chat`传输：推理前后核对安装摘要，无工具/命令/网络例外，网络总期限30秒、子程序40秒、输入输出各64KiB，模型回复必须完整且停止原因正确。独立模型服务仍由维护者管理，终止客户端子程序不保证服务器计算立即停止。

原请求固定work ID、2至4个Python路径和1至2个明确新候选测试。新请求必须来自当前合理评估、路线图选择及准确prepared记录。公开Issue和准确main代码观察均在事务外读取，随后在需求库短锁期间重新核对来源与原准备记录，才向独立模型日志预留；推理不持有该锁。完整公开源码每文件/合计最多32KiB，原正文最多1024字符并显式标记截断；不悄悄裁掉文件。控制器、来源/租约/审核边界及其他原保护路径在提交模型前拒绝，模型自身的`development_model*`也属于既有保护前缀。

模型只提供标题和完整LF文件文字，每文件最多32KiB、总新文字48KiB。结果必须准确覆盖原选路径，至少改变一个原业务文件，保留原测试选择。旧文件哈希、work身份、原base/准备摘要及稳定bundle请求键均由控制器构造，模型不能改写。所有文字保持惰性，不通过模型声称、文本解析或保存测试文件来判定通过。

独立`local-code-model.sqlite3`有四张追加表，分别保存原repo/profile、发送前意图、模型结果和bundle关联。原键并发只有一个发送者；最多128次本地请求、每个work 8次、总历史32MiB，按实际UTF8字节并给每个待处理结果和关联预留容量。UPDATE、DELETE、REPLACE及显式rowid替换被拒绝，读取重新校验类型、哈希及模型结果与bundle输入关系。失败或结果不明仍保留原名额，不自动重新调用模型。

模型结果先独立提交，再尝试保存bundle。保存使用原公开base commit和原prepared work摘要，拒绝隐式换main或换准备记录；原来源撤回、版本/计划变化时保留已生成文字，不能新建提案。原模型回复丢失时可恢复已存文字；bundle已经写入而关联步骤中断时，先恢复原bundle再考虑当前来源。恢复旧惰性记录不赋予新执行权。

后续仍通过[原候选提案流程](../community-changes/)形成可审阅提交，通过独立隔离检查、PR/CI/审核及预览策略各自准入。实际AI编码质量、真实GitHub App到PR/发布的联合流程与公网仍未验收；本轮只用自作本地HTTP响应和公开源夹具测试软件，不下载或运行真实AI模型。
