# Agent 配置持久化

Agent 管理页使用 `/api/v1/agents` 的类型化接口，配置存于 `agent_configs`，已保存修订存于 `agent_config_revisions`。列表为空时返回空集合，不再请求旧 Mock 的 `/api/agents`。

可保存名称、分类、说明、全局提示词、温度、Top-P、提取参数与工作流节点。节点支持添加、删除、排序、名称和提示词编辑，开始与结束节点保持固定边界。界面刷新后从数据库恢复这些字段。保存可携带当前版本；陈旧版本返回 409，不覆盖已有更新。

复制创建独立身份。收藏与同分类默认选择分别保存；数据库部分唯一索引限制同一分类只有一个默认项。每次实际变更形成完整历史，恢复旧版会创建新修订而保留原历史。删除配置同时移除其自身历史。

导出使用 schema_version=1 的配置封包，排除数据库身份、时间及创建者字段，不携带模型密钥。导入使用新身份且不会替换当前默认配置。未知字段、重复节点、错误起止顺序、越界参数和超限配置均被拒绝。

配置编辑与模型执行分别操作。保存、导入、复制和读取历史均不调用模型。进入“执行与记录”选择已配置的文本模型、提供输入并明确确认后，已保存版本可执行 1 至 8 个顺序 LLM 节点；真实节点输入输出和失败记录保存在独立执行表。未配置模型时执行按钮展示原因并禁用。完整执行、取消和显式重试语义见 [Agent 工作流执行](./agent-execution)。
