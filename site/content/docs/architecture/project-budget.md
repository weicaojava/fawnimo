# 项目预算

预算按单个项目管理。每个项目拥有独立的累计上限、任务预留、已结算金额、可预留余额和明细；项目之间不共享额度，不存在工作空间总上限。工作空间仍用于身份和业务数据归属，不再作为费用预算的汇总限制。

`execution_budgets` 按 `project_id` 保存额度，持久视频提交在 SQLite 写事务内创建任务、绑定和预留。并发提交不能超过本项目上限，同请求标识恢复不会重复预留。未知接收继续保留额度；只有确认未被接受或可信费用结算才能释放相应额度。取消意图或结果就绪不等于免费。

`GET/PUT /api/v1/video-runtime/projects/{project_id}/budget` 读取和修改本项目上限。余额、费用状态、账单与待补金额在真实 SQLite 读快照内读取；修改使用预期修订 CAS，新上限不得低于本项目已预留、已结算与已导入待补账单金额之和。`project_budget_changes` 与修改事务一起记录项目、可信操作者、旧/新上限及修订，不可改删。身份模式下只有受信 owner 可以调整；其他成员只读，旧标签和伪造角色不能替换当前身份。独立本地模式使用服务端固定的本地操作者记录。

`GET /api/v1/video-runtime/projects/{project_id}/budget/entries` 先验证项目归属并限定项目，再按记录标识分页。它返回项目、额度状态、金额与来源（视频任务、模型调用、账单差额或未分类），不返回供应商请求标识、提示词、凭据或结果 URL。精确金额同时返回十进制整数字符串，避免前端浮点丢失；另一个项目的游标不会改变查询范围。

界面位于“项目 → 项目设置 → 项目预算”，执行任务面板复用同一组件。系统设置不再展示预算。新项目未配置时显示零额度；保存预算不会充值、扣款或启用生成。

升级时，`migrate_project_budget` 在同一 SQLite 写事务中移除旧工作空间总预算的预留拦截及修订触发器，将旧控制和修改记录分别归档为只读 `retired_workspace_budget`、`retired_workspace_budget_changes`。项目上限、预留、结算、未知状态和任务记录不被改写；旧总上限不会分摊给项目。归档冲突会中止迁移，避免覆盖历史。固定空间 worker 完成迁移后重新检查所有业务表的空间归属。旧 `/video-runtime/workspace-budget` 路径在网关返回410，不再接受预算写入。

通用模型调用预留、连接版本与人工账单核对的内部基础见[模型费用与账单](../model-accounting/)。人工导入后，页面显示已核对全额、未补入金额、授权缺口和价格上界异常。重叠账单按同一调用的最高观察总额计算潜在费用，扣除已完整结算或仍预留的部分，保留每份证据和未决记录，不重复占额度。修改上限不会自动确认账单、释放未知费用或发起生成。

当前实际生成准入仍覆盖持久视频任务；文本、图片、视频理解等运行时尚未接入通用费用基础。人工规范化账单不代表供应商自动认证，`provider_bill_verified=false`，收费网关继续关闭。合成测试金额只能证明软件行为，不授予真实费用、模型质量或公网资格。
