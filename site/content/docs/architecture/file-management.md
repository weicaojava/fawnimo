# 文件管理与二进制下载

全局文件页通过生成客户端读取 `/api/v1/studio/files`。它读取完整分页，支持文件名与标签筛选、按页选择、刷新、上传、标签保存和下载。标签修改调用真实 PATCH 接口，再读取服务端结果；部分失败时明确提示，不能仅弹出成功消息。

单文件下载通过生成客户端接收原始 Blob。`front/openapi/request.ts` 是生成器使用的请求模板：JSON 保持对象，文本与事件流保持文本，其他二进制 MIME 保持 Blob，避免 UTF-8 文本转换损坏图片或视频。`openapi:gen` 的 `--request` 参数保证重新生成后仍保留这一行为。

`GET /api/v1/studio/files/export-bundle` 接受 1 至 20 个文件身份，通过与单下载相同的已验证存储读取函数读取全部内容，返回真实 ZIP。总原始大小上限 32 MiB，文件名清理路径分隔符和控制字符，按顺序加前缀防止重名。任何文件缺失、不可读或超限时整个导出失败，不交付不完整压缩包。

上传与下载使用已配置的实际存储后端。文件 API 成功不代表视频生成、语音或模型资格已通过验收。
