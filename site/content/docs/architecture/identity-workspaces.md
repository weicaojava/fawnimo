# 身份网关与固定工作空间

新增身份体验使用 `backend/run_controlplane.py`，本机启动示例使用 `http://127.0.0.1:18000/projects`。它使用独立数据根，保留原 `17888` 前端、`8000` API 对应的本地工作区；原入口没有切换或自动认领。两个入口都不是公网平台。B 与 C 仍为部分交付；业务资源、嵌套引用与历史文件隔离通过本机正反向矩阵和实际双账号浏览器检查，详见[业务资源隔离](/docs/architecture/resource-isolation/)。持久视频按项目设置独立预算，旧数据离线迁移/回退工具完成私有副本演练；单独SQLite文本/连接测试/图片及原片视觉/ASR已接项目费用与人工规范化账单；托管原生视频也已接入单份原项目预留与共同账单；全部收费A/B联合隔离及真实供应商账单认证尚未完成。

## 可信身份与个人空间

独立 `control.db` 保存用户、个人资料、成员关系、工作空间、可撤销会话和请求审计。账号建立时在同一事务创建个人空间与 owner 成员，登录只读取受信成员关系，不因首次登录认领现有业务数据。底层成员角色为 owner、editor、viewer；空间切换只允许当前成员所属空间，尚无团队邀请管理界面。

密码使用独立随机盐的 scrypt 哈希；会话为随机不透明值，库内只存会话哈希，默认有效期12小时。浏览器 Cookie 为 HttpOnly、SameSite Strict，默认 Secure。仅显式回环测试参数允许纯 HTTP Cookie。每次请求重新检查会话有效期、账号状态与成员关系；退出撤销库内会话，登录失败计数持久保存。资料、语言和主题归用户，保存在身份库，不归当前工程或空间。

## 固定数据库、文件根与执行进程

网关从已验证身份选择服务端生成的空间 ID，再由 `WorkspaceWorkers` 启动该空间专用的 loopback 工作进程。每个空间固定使用自身的 `studio.db`、`files/`、`media/` 与执行器；请求不能传入数据库路径、工作进程地址或内部令牌。工作进程由网关持有进程树所有权，默认最多4个活跃空间进程，达到容量时拒绝新增，不驱逐已有运行任务。

worker 在 stdin 所有权门控后配置环境、导入应用。环境使用允许名单，不继承原主机模型、云存储、代理或共享 Celery 凭据；数据库、文件和媒体根均按固定空间设置。内部 HTTP 入口要求网关生成的私有令牌。进程和目录拆分是应用隔离边界，不是操作系统账号或容器安全隔离声明。

新数据库完成受支持迁移后，`workspace_boundary.py` 为私有业务表添加非空固定 `workspace_id`、一致性约束及写入触发器。`workspace_identity` 只允许当前固定身份且不可改删；启动会核对 marker、列默认值、写入约束和引用完整性。普通 ORM 和 raw SQL 新记录均不能写入另一个空间 ID。独立库内的引用仍受现有工程/章节归属及外键约束。

未标记且包含业务数据的库拒绝初始化，目录或文件路径不能重定向到另一个位置。普通启动仍拒绝非空旧库；维护者可使用[离线迁移/认领/回退工具](/docs/architecture/workspace-migration/)制作私有备份包并明确认领到尚未初始化的目标账号目录。工具通过独立副本演练，原入口尚未正式切换；不允许公开注册或首次登录自动认领资料。

## 旧标签、媒体与恢复意图

前端取得身份后，才挂载私有业务页面；generated client 绑定可信响应中的 `X-Identity-Id` 与 `X-Workspace-Id`。网关将它们与当前 Cookie 对应身份比较，旧账号或旧空间标签返回409。图片、视频和原生下载链接附带非秘密的 `__studio_user`、`__studio_workspace` 范围参数，避免浏览器共享 Cookie 变化后把原媒体链接静默转到新身份。

业务恢复记录使用 `studio:{userId}:{workspaceId}:` 前缀隔离 localStorage，原请求 key 仍保留原值。切换空间或退出后整页加载；不把网络结果未知的请求改成新标识重发。实际浏览器已验证换账号后旧标签读写和媒体被拒绝；收费重试与复杂后台竞态仍单独验收。

## 当前执行与费用门禁

新身份空间允许本地编辑、文件、配置和只读任务查询。旧 Film、脚本处理及共享图片任务入口的写入被网关拒绝；只读任务可以读取本空间状态。持久视频任务使用项目独立预算、零额度默认值、所有者修改收据与本项目分页明细，详见[项目视频预算](/docs/architecture/project-budget/)。工作空间没有合计费用上限。单独SQLite的六种有界协议已有项目费用接线；固定身份worker只读取自身private/model-prices.json与private/native-video.json，未认领或导入锁定空间不加载原生视频配置，主机路径和key不继承。完整收费A/B联合验收未完成。未明确开放的空间及其他协议的收费提交、重试与回调继续503；下节分别声明图片与其他执行类型准入的软件边界。保存正上限或连接配置不会启用模型调用。

原本地工作区的工程预算和生成协议仍按原模式运行；项目额度仍须在所属空间内绑定正确项目及可信身份，不能代替实际账单对账。当前没有本阶段真实模型或完整成片通过结论。

## 默认关闭的独立图片准入

维护者在网关固定数据根的`private/asset-image-admission.json`明确列入最多16个空间。配置不包含费用上限，金额仍归属原项目。缺失、禁用或无效策略保持关闭，运行后文件字节变化关闭新准入，明确重启才加载新策略。原任务读取与费用记录仍可使用，已接受任务不会被策略文件变化自动取消。

可信身份、成员写权限、体验只读及旧入口限制先执行；图片仅允许演员/服装/场景/道具槽位POST和显式重试。网关独立检查当前策略与固定worker的启动grant，再在原请求审计事务中追加WITHOUT ROWID不可变策略见证，绑定原用户、空间和策略摘要。浏览器传入的内部令牌或策略头不能选空间、改权限或绕过项目费用。

固定worker通过私有stdin绑定当前空间，ready响应核对grant，图片提交额外检查网关自己的策略摘要头。导入锁、每空间报价/服务和原项目预算继续独立生效。只有当前策略和同一worker绑定成立时才透传图片可用性；图片开关不开放其他收费；其他执行类型须另行明确配置，回调仍关闭。

新增40项及相关359/1本机回归、真实双身份工作进程和编译页面17项通过；传输、图片和报价均为自作，真实供应商质量/账单、全部收费协议与公网尚未验。启用方法见[身份空间图片生成准入](/docs/guide/workspace-image-generation/)。

## 默认关闭的其他执行类型

固定`private/execution-admission.json`另外列出精确空间及四类操作，不接收金额、端点或凭据。当前策略、私有stdin/ready及请求策略头共同核对固定worker；原审计事务追加不可变的用户/空间/操作/策略见证。查看者、体验只读、项目费用和导入锁先后独立生效；图片仍是另一份策略，回调与旧共享写入口不开放。

真实双worker和自作HTTP覆盖文字、连接测试、剧本、图片、ASR/视觉及原生接受/查询。新增66及原冻结429/1、继承图片测试修订10分记；真实账单、完整操作链、模型质量及公网未验。启用与暂停见[执行类型准入](/docs/guide/workspace-execution-admission/)。

## 纯自作示例与幂等恢复

`POST /api/v1/identity/demo` 从当前会话取得用户与空间，服务再次核对真实成员写权限。它通过该空间 worker 的实际项目、章节、镜头与镜头细节 API 建立《点亮小岛》文字练习：7个 pending 镜头，以及每镜首帧、尾帧、关键帧3条、共21条可编辑提示词。没有导入用户原片，没有生成图片、视频或模型任务。

控制库的 `demo_requests` 固定用户、空间、请求 key、模板版本、内容 hash 和确定性工程 ID，使用租约与确认步骤记录 pending、succeeded、failedunknown。失联后同 key 先核对真实资源；已确认内容改动或删除时返回409，不覆盖或重建。成功请求重放返回原工程，保留后续编辑。用户主动新建示例用新 key 建立全新工程，保留旧示例；每空间最多20次新请求，原请求恢复不增加次数。

本机 A/B 账号已安全建立，示例服务和 API 已实现；项目大厅按钮、示例重建及保留旧编辑的本机浏览器检查已通过。账号凭据不进入公开仓库，公网注册/领取、额度与稳定/预览体验尚未交付。

另有 `POST /api/v1/identity/demo-exportable` 建立全新的原创可导出示例。它通过空间私有RPC，在一次事务内保存7段无声素材、图片、剧本与计划、导入采用、剪辑草稿和完成引用；与文字入口共用20次上限。原请求恢复保留后续编辑，7条剧情标记须显式确认后才能锁定导出。媒体和完成记录的边界见[原创示例架构](/docs/architecture/original-example/)，页面步骤见[体验指南](/docs/guide/original-example/)。

## 当前证据与边界

此前身份示例通过43项新增后端、16项原模式回归及46项浏览器检查。原总预算方案已按用户要求停用；当前按项目预算通过后端回归与25项实际浏览器检查，独立检查覆盖旧规则移除、历史保留及真实进程升级。离线迁移另完成原9工程、29文件记录及95本地文件的私有副本认领/回退与11项浏览器检查，原库未改且正式账号未切换。新增资源矩阵与58项实际浏览器检查覆盖根资源、嵌套引用、历史和真实文件；独立检查另核对同空间不同项目、相同ID、模型默认设置、恢复与真实进程边界。不同轮次存在重叠，不能直接相加。收费执行、所有模型费用、实际账单、完整成片和公网仍未通过。证据索引与功能状态统一见[功能总表](/docs/reference/feature-catalog/)。

稳定/预览同一候选镜像在2ced83d精确提交的GitHub Linux runner完成实际构建与40项容器检查，双账号/独立卷、文件/预算和删除重建持久数据、测试资源清理通过。8项拒绝方法及30项原生断言分记；这不证明公网、备份回退或浏览器制作链通过，详见[容器验收](/docs/architecture/workspace-container/)。公网部署仍为未部署，单节点SQLite的并发、恢复与回退仍待实际部署验收。操作说明见[工作空间体验](/docs/guide/workspace-experience/)，剩余门槛见[分阶段计划](/docs/plans/platform-delivery/)。


剧本候选新建也在关闭的收费门禁内；规范末尾斜线后，等价收费写入及回调均在选择worker前503。其可用状态被网关改为关闭。单独工作室的候选软件通过不代表全部收费身份空间已开放或已验收。


剧本任务摘要也从登录身份选定的固定worker读取。自作A/B测试故意复用项目、章和模型ID，通过内部HTTP构造保留失败记录后，经实际网关验证只返回本空间run、原来源和原费用提交人；另一身份的读取、采用、忽略均404且不改原预算。内部运输在本地模型socket前拒绝，公开收费门禁仍503；这不是完整模型收费A/B执行资格。


固定worker的自作本机模型例外按自身owner和协议端口读取，配置/实际执行范围见[本机模拟](../workspace-local-models/)。六类费用协议的私有HTTP正向回归不等于公开收费开放；错owner文件、端口串用、在途取消/停worker和原请求恢复另有窄补测。原应用及迁移锁保持独立，完整收费身份资格仍未验收。

固定身份参考视频另有[显式签名只读交付](../workspace-reference-delivery/)。私有身份根与前端静态目录必须互不包含，启动前核对；默认关闭，工作进程只收到自身派生密钥，原项目费用和公开收费503保留。真实供应商与公网尚未验收。

## 原请求与执行动作的检查

已声明独立协议的公开网关动作以实际双固定worker和自作HTTP验证：500失败、确认新重试、重试原key重放、已到达HTTP时取消、原生暂停/恢复/取消，以及连接更改后的原key恢复和旧报价拒绝。冻结58含新增14全通过；应用代码、API及前端未改，原项目未知费用保持，不能把取消当作退款。不支持的回调和旧共享写入口继续关闭。操作说明见[原执行恢复](/docs/guide/workspace-execution-recovery/)。
