# Agent 工作流执行与文本连接测试

Agent 配置 CRUD 仍使用 `/api/v1/agents`。执行使用独立的 `/api/v1/agent-execution`，前端统一调用生成的 `AgentExecutionService`。配置保存、打开连接测试面板、读取可用性与历史均不调用模型。可用性仅在 SQL 中判断密钥是否存在，不将密钥返回界面。

## 当前执行边界

执行固化已保存 Agent 的版本、提示词、提取参数、节点顺序与所选文本模型。配置可编辑最多 32 个节点，实际执行要求开始、1 至 8 个 LLM、结束组成的顺序链。当前没有分支、并行图、代码执行或任意工具节点；图片与视频不经过此文本运行器。

开始节点传递用户输入。每个 LLM 节点使用全局提示词、节点提示词和结构化提取约束组成系统消息，以前一个节点的实际输出为用户消息。节点温度、Top-P 覆盖默认值；界面中的全局采样默认值用于新增节点。结束节点传递最后结果。每个模型节点的输出上限由提交参数约束在 8 至 2048 tokens，输入文本最多 32000 字符，响应有字节和文本大小限制。

文本适配器使用现有供应商注册与基础地址解析，支持注册为文本能力的 OpenAI-compatible 供应商。模型参数仅允许可验证的 `frequency_penalty`、`presence_penalty`、`seed`、`stop` 进入 HTTP，不接受模型 JSON 注入路由、凭据或任意 headers。供应商密钥只在明确提交后的工作进程读取，连接快照和结果不保存密钥。供应商配置改变时，已排队任务失败而不转向新的模型地址。

## 持久任务与租约

`agent_execution_runs` 保存不可变配置快照、模型绑定、请求标识、状态和重试关系；`agent_execution_nodes` 保存每个节点的输入、提示词、实际参数、输出、数字用量、时间与错误。删除源配置不删除独立执行历史。

提交使用作用域和请求标识唯一约束。同一标识、相同内容返回原任务，改变内容返回 409。请求事务在完整记录和节点入库后提交，扫描器只发现已提交任务。SQLite 使用原生 conflict-safe INSERT，避免最外层 SAVEPOINT 提前可见。数据库实现支持 SQLite 和 PostgreSQL；当前验收使用隔离 SQLite。

扫描器使用条件更新把 queued 变为 running，并领取随机租约。节点写入、续租、最终结果和错误收尾均要求状态、令牌和有效期仍匹配。HTTP 调用期间不持有数据库写锁。多个扫描器不能重复执行同一领取任务；过期运行任务变为明确的“结果未知”失败，不重新发送模型请求。

## 取消和重试

网络调用使用现有 DNS 固定、有界响应、硬截止、可终止的独立 HTTP 进程。每个节点只发送一次请求，没有 SDK 自动重试或 POST 重定向。运行器监控持久取消状态并终止网络进程，取消后不会采用迟到结果。已发出的供应商请求仍可能计费，软件不能撤销供应商侧费用。

服务停止或进程失联后，进行中的请求不会自动重放。失败与取消可以明确创建新 attempt，保留原历史；界面须确认从头执行全部节点及可能重复费用。模型绑定改变时拒绝沿旧任务重试，需要新建执行。幂等标识在前端提交结果不明时复用，避免网络失联后重复 admission。

## 文本连接测试

模型管理中的文本模型可打开连接测试面板，查看真实历史。确认后通过相同持久任务和适配器发送一次固定 `ping` 请求，最大输出 8 tokens。记录显示成功、失败或取消及实际响应；不会把模型保存、默认选择或测试面板打开当成成功。图片与视频连接按钮不借用这项文本结果。

本地 HTTP fixture 验收只证明软件参数、依赖和状态闭环。真实账号连通性、模型质量、图片及视频生成资格均需分别验证；本轮外部模型与收费调用为 0。
