# 业务资源与历史文件隔离

身份网关从每次验证的会话和成员关系选择工作进程。每个进程固定一个数据库、文件根和媒体根，业务 ID 不决定工作空间。相同的工程 ID 可以在两个空间中分别存在，读取、编辑和删除只作用于当前已验证空间。

当前资源检查使用 `backend/tests/test_workspace_resource_matrix.py`：真实 ASGI 网关由测试客户端调用，网关启动两个独立的 loopback 工作进程。测试账号、内容、PNG、短 MP4、字幕和 ZIP 均为自造夹具；不会打开用户的旧工作区或调用模型。它验证本机应用的资源授权，不是操作系统账号、容器或公网安全证明。

## 根资源与嵌套引用

矩阵覆盖工程、章节、镜头、镜头细节、演员、角色、服装、场景、道具、提示词、Agent、供应商、模型和文件。每类资源具有真实的拥有者读取和修改正向，交叉读取、修改和删除随后核对拥有者原值。另建一组可删除资源，实际删除后读取404，原资料仍保留。

列表和搜索必须实际包含自有资源，不能仅凭空列表200通过。外部 ID 在当前数据库中被视为不存在。旧 CRUD 的部分删除接口对不存在 ID 返回空成功；测试要求它与随机不存在 ID 的响应完全相同，并证明其他空间的原行仍在。这种幂等结果不表示获得删除权。

嵌套检查包括工程/章节/镜头、角色与演员/服装、场景、提示词、模型供应商、文件用途和图片槽位。相同字段先验证本空间有效引用，再验证外部引用失败。失败的新建 ID 不存在，失败修改保持原字段，失败上传不遗留文件。项目制作资产、版本、媒体、编辑草稿和镜头结构恢复收据还必须匹配其所属项目。

## 文件、历史和浏览器

文件下载核对实际 PNG 字节与 HTTP Range。原生图片链接同时绑定可见用户和空间；换账号后的旧链接返回冲突，不能随新 Cookie 静默改变资料归属。ZIP 在所有选中文件验证后才生成，混入外部文件时不返回部分归档。

章节文本历史、恢复、Agent 修订与导出、项目预算和分页明细均在原空间内读取。v1 与 v2 导出历史分别检查任务状态、终态取消、视频、SRT、VTT 和 ZIP：拥有者获得与夹具逐字节一致且哈希匹配的文件；外部任务或错误项目路径返回404。

导出历史夹具由测试直接登记，媒体确为 FFmpeg 自造的短 MP4。该检查证明已有历史文件的读取和归属，**不证明**它经过了真实剪辑冻结/渲染流程，也不授予完整成片资格。历史 Agent 和图片任务同样明确为合成失败记录；取消是终态幂等检查，不冒充远端运行中取消。

实际浏览器另检查两个独立会话的项目大厅、模型管理、项目预算、原生图片和文件 Range。一个会话切换账号后，旧标签的读写、媒体链接与收费意图在范围核对阶段被拒绝。模型页支持 `tab=providers|models|settings`；任务回跳和浏览器导航会恢复对应页签，指定连接模型时进入模型页签。

## 与收费执行分开记录

供应商响应不包含密钥；数据库中的合成凭据在对应空间内保留。任务汇总不返回提示词、输出、供应商地址和凭据。请求审计记录可信用户、空间、正文摘要与响应状态，不保存正文中的密钥。

收费提交、重试和回调仍由网关拒绝。503 只证明门禁保持关闭，不能证明真实模型的提交、执行、重试、取消、采用或账单隔离已完成。F-001.04、其他模型的项目费用和供应商账单对账继续单独推进；工作空间没有合计预算上限。

具体检查数、代码摘要与边界见 `capabilities/resource-isolation-validation.json` 及[功能总表](/docs/reference/feature-catalog/)。相关身份和离线迁移规则见[固定工作空间](/docs/architecture/identity-workspaces/)与[旧数据迁移](/docs/architecture/workspace-migration/)。
