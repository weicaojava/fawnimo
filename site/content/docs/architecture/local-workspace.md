# 持久本地工作区与功能边界

实际网站使用 `backend/run_workspace.py` 启动的本地 SQLite 工作区，不再连接外观改版的临时验收库。首次迁移采用一致备份，保留原有记录与媒体；后续启动保持已有数据库，并在迁移前生成一致备份。当前本机工作区位于 `work/local-studio/`，页面地址为 `http://127.0.0.1:17888/projects`，API 仅绑定本机 `8000` 端口。

本地文件使用 `STORAGE_BACKEND=local`，无需 S3。文件上传有大小与路径约束，生产媒体按原记录校验大小及 SHA256。下载支持真实字节和单范围 HTTP 206，浏览器可以定位视频时间；不合法范围返回 416。文件 ZIP 先验证所有成员，再返回有数量和总大小上限的真实归档。项目归属检查也覆盖演员、服装的原片参考图片。

数据库请求使用函数生命周期的依赖，提交完成后再发送成功响应。独立回归在 ASGI `http.response.start` 时通过另一连接确认新记录已经可读，避免连续创建镜头和详情时读不到前一步写入。

项目接口返回数据库真实的创建与更新时间，SQLite 的无时区 UTC 值补回 UTC 标记，不用浏览器当前时间替代。项目列表通过 generated client 指定最近更新降序并读完所有服务器分页，之后才进行本地搜索与排序；分页缺漏或加载期间的记录变化显示可重试错误。章节接口未提供的时间保持未知。

## 资料拆解进入制作

DNA 草稿现在可以显式导入为待确认制作资料。预览展示实际计数，导入绑定工程、草稿修订、原片哈希与原始帧时钟。演员和服装会写入可见资产库，同时关联角色与制作版本；场景、道具、逐镜图像及视频提示词也会保存，并建立新章节、分镜和镜头计划。

一次导入与来源收据在同一事务提交。收据保留完整原声明、源、修订、内容哈希、映射和返回身份；同意图重放返回原结果，修改意图或导入后新修订明确冲突，不覆盖已有章节。参考图限定本工程，最多64张且总量不超过32MiB。所有导入镜头保持待确认，原 `human_reviewed=false` 不会被改写，也不会生成模型任务。

私人原片工程、媒体和来源收据保存在用户工作区，不随代码或开源示例发布。导入保留真实帧时钟、观察、推断与未知项；未知末端不通过标称帧率补齐。公开体验示例使用独立自作内容，不能作为私人原片还原或真实模型质量验收。

## 当前功能状态

| 功能 | 当前状态 |
| --- | --- |
| 项目、章节、演员、服装、场景、道具、提示词 | 持久化接口和实际页面可用；验收记录见工作区 `outputs/functional-repair/` |
| 文件上传、标签、单下载、ZIP下载 | 实际保存与二进制校验通过 |
| Agent配置、工作流节点、修订、复制、导入导出 | 实际保存；另有1至8个顺序文本节点的持久执行、取消和显式重试，见[Agent执行](/docs/architecture/agent-execution/) |
| 章节原文和精简文本历史、恢复 | 实际修订与CAS保护；恢复形成新修订 |
| 原片技术解析、DNA编辑、草稿入库 | 可用；观察与推断、未知项和待确认状态保留 |
| 工作室复制、末尾插入、预览步进、截帧 | 实际操作；不复制生成任务或采用资格 |
| 分镜重排、中间插入、合并 | 新的全图修订、指纹和事务接口；已被历史文档引用的镜头合并会明确保护，收据保留原图 |
| 交叉淡化 | 独立v2草稿/锁定/本地渲染，保留旧v1硬切契约；保护剧情/对白锚点，输出时长扣除重叠，字幕按输出位置平移 |
| 新视频视觉与ASR理解 | 新的持久理解任务发送实际原帧/带时钟音轨，结果为未审核候选；真实模型语义准确性尚未验收，见[视频理解](/docs/architecture/video-understanding/) |
| 资产图片生成 | 独立单张文生图协议、真实PNG/JPEG候选、显式CAS采用到四类资产槽位；不替代原参考图或声称人物参考能力，见[图片生成](/docs/architecture/asset-image-generation/) |
| 文本模型连接测试 | 明确确认后单次8-token文本请求，持久记录与刷新读取；进入模型页不会自动调用 |
| 视频生成服务与工程预算 | 显式主机配置可连接受信提交、接收和采用流程，默认关闭；预算与未知费用预留不混用，见[生成配置](/docs/architecture/workspace-video-runtime/) |
| 真实模型、完整成片与还原质量 | 尚未完成联合验收；本地模型协议夹具与真实媒体渲染均不能代替这些质量结论 |

当前用户工作区没有启用新的收费调用。Agent、视频理解和图片任务各有独立配置及明确提交入口；旧Film/Celery动作仍未由这些执行器授权，不会因为视频服务可用就被错误放开。手动编辑、保存、上传和来源导入可用。软件开发与验收使用独立工作区和本地HTTP夹具，不改变历史阶段或真实生成资格状态。
