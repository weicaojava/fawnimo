# 全局资产图片候选与明确采用

演员、服装、场景和道具编辑页提供“生成图片候选”，调用 `/api/v1/asset-image-generation` 和生成的 `AssetImageGenerationService`。生成只新增候选，单独确认采用才更新原定图片槽。它不经过旧 Film/Celery 任务，不依赖视频执行可用性，也不自动把候选转成工程 ProductionMedia。角色实例、参考视频生成和人物一致性质量不在此入口的验收范围。

## 明确声明的三种协议

模型管理在图片模型上保存 `params.asset_image_protocol`。开关、编辑配置和读取历史均不自动调用模型。旧文本协议要求 `openai` 供应商，Seedream要求火山引擎 `volcengine` 供应商；不能互换。模型地址、凭据和下载域名来自服务器保存的配置，不能由生成请求携带。

| 协议 | 当前输入与输出 |
| --- | --- |
| `openai_b64_v1` | 兼容原文本流程：256、512、1024方图；发送 `n=1`、`response_format=b64_json`；只接受恰好一张base64图片，不接受参考图或URL结果。旧任务绑定及默认空参考图的幂等指纹保持原域。 |
| `volcengine_seedream_json_v1` | 固定单张协议；支持0至3张原项目参考图，以及明确选择的base64或受限URL结果。尺寸限定为2048×2048、2848×1600、1600×2848，输出必须真实解码并匹配所选尺寸。 |
| `openai_gpt_image_json_v1` | 0至3张原项目参考图；固定两个GPT Image 2.5快照、medium质量、单张不透明PNG，三种标准画幅，不接受URL结果。 |


`openai_gpt_image_json_v1`要求`openai`供应商，确切模型只能为`gpt-image-2.5-sunburst-2026-09-08`或`gpt-image-2.5-flare-2026-09-08`。固定medium质量、不透明单张PNG、关闭流式，尺寸为1024×1024、1536×1024或1024×1536。无参考图调用生成接口，有参考图通过JSON的`images`传送完整已验证data URL至编辑接口；不接受网页提供的URL、file ID、mask、任意参数或返回方式回退。不给该GPT档案发送旧`response_format`字段，也不下载结果网址。依据[官方图像编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)与[生成接口](https://developers.openai.com/api/reference/resources/images/methods/generate)，核对日期2026-11-04；软件声明不证明真实账号可用或画质。

新档案使用独立`gpt_image_input_sets`和`gpt_image_references`，两表均为SQLite WITHOUT ROWID。原排队任务、原项目费用、准确连接摘要和完整参考证明同事务封存；初始/密集顺序/封存/更新删除替换均受固定守卫约束。既有Seedream表、旧文字请求指纹和已接受历史不改写。结果HTTP身份先保存，再校验单张真实PNG及准确尺寸；失败、取消和不明结果沿用原项目费用规则。

冻结73项中72通过/1平台跳过，新增23项全部通过；16项镜像验收守卫、4种生成DTO及3219模块构建通过。独立自作本地服务上的完整页面9项检查覆盖参考选择、画幅、确认、采用、当前页面原请求恢复与服务器历史刷新。恢复闭包只属于仍挂载的原页面；刷新/离开前先核对历史，刷新后读取原服务器任务，不声称浏览器保存了完整原提交。真实非root只读镜像另有固定文字/参考图2例，须准确本轮CI附件证明。身份图片准入可由维护者明确配置，其他收费提交仍关闭，实际供应商/账单、A/B、人物一致性及公网仍未验。

Seedream只接受确切名称：`doubao-seedream-5-0-pro-260628`、`doubao-seedream-5-0-flash-260915` 使用 `single_v5`，不发送 `n`、`stream` 或 `sequential_image_generation`；兼容的 `doubao-seedream-4-5-251128`、`doubao-seedream-4-0-250828` 使用 `single_v4`，固定关闭连续组图与流式输出。水印固定开启。不转发任意模型参数，也不将未知模型或Endpoint ID猜作已支持模型。4.x是旧版兼容配置，供应商文档已列入即将下线范围。

协议依据为[方舟图片生成API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh&redirect=1)和[模型列表](https://docs.volcengine.com/docs/ark/model-list?lang=en)，核对日期2026-11-02。声明协议不等于真实账号可用或画面质量已验收。

## 原项目参考图与不可变输入

参考图只能选择本次明确费用项目中的 ProductionMedia，或通过项目媒体上传入口新增。每张保存媒体ID、原项目、期望SHA256、顺序和用途（外观、构图、风格），不接受客户端图片网址、磁盘路径或凭据。最多3张，每张4MiB、合计12MiB；仅单帧PNG/JPEG，边长15至4096、最多1600万像素、长宽比介于1:16和16:1。列表及上传返回有类型的媒体信息，不返回存储路径。

准入先在SQLite写事务之外有界读取并实际解码图片。独立解码子进程有输入、输出和时间限制，继承清理后的环境；父进程持有校验后的同一份内存bytes。事务内仅复核媒体归属、元数据和文件见证。发送前重新验证持久证明，实际发出的data URL由这份已校验bytes组成，不在最后检查后另读文件。文件被替换、SHA或原项目不符时拒绝，不忽略参考图降级为文生图。

`asset_image_input_sets` 与 `asset_image_references` 保存Seedream的强制完整头部和有序证明。头部绑定任务、原项目、财务身份、连接、精确模型/profile、尺寸、格式和参考图集合；复合外键核对媒体项目。引用先完整插入，再在任务与费用预留的同一事务密封。触发器拒绝更新、删除、REPLACE、密封后追加和跨项目重绑。旧协议任务不能补加新头部。缺少或损坏完整头部的任务在准备收费与POST之前失败。

## 费用、任务与结果

首次生成必须明确选择费用项目，并确认受信 `asset_image` 价格指纹。报价上界须覆盖所选协议允许的最大输入和输出。任务、完整输入与一次预留在同一 `BEGIN IMMEDIATE` 事务保存。参考图协议继续使用原 `asset_image` 费用kind，不新增费用分类，也没有工作空间总预算。全局资产可供多个项目引用，但这次费用始终归属原选择项目。

工作进程采用 queued→running 的CAS租约。旧协议租约75秒，新Seedream协议150秒；新协议对参考校验、60秒POST、15秒GET及解码分别设限。参考图有独立有界校验通道，竞争中的新参考提交可返回429，空参考图和旧协议不被这一新通道额外拒绝。候选发布必须仍持有有效任务令牌和租约；取消会终止并等待自有网络进程退出，迟到结果不能发布。已发送的远端请求可能计费，不自动重发或释放未知费用。

Seedream响应严格解析JSON，拒绝重复字段、NaN、Infinity及指数溢出，要求恰好一个与所选返回格式一致的结果，不自动切换协议。POST返回的私有请求标识先保存到原费用记录，再解析图片或执行下载；后续失败、取消或下载超时不会丢掉已接收的POST证据，也不能据此推断免单。真实PNG/JPEG输出受8MiB、边长和像素限制，并校验尺寸、MIME及SHA。

URL结果仅在管理员配置最多8个确切公共下载主机时可选。每个请求固化原主机政策，配置改变后旧排队任务不能借用新政策。GET限HTTPS/443、确切主机、公共DNS及固定解析地址；不发送模型凭据或Cookie，不跟随重定向，不复用测试POST允许本机地址的例外。不接受通配符、IP、端口、网址或本地域名。供应商返回的签名URL只用于当次有界读取，不进入公开任务或错误信息。

候选文件写入服务器生成的私有独占路径，完成暂存、fsync和原子发布后，仍需有效租约CAS才对内容端点可见。持久请求、已成功候选及采用身份受不可变约束保护。内容、通用文件预览、下载和ZIP读取固定本地bytes并校验大小与SHA，不暴露路径或供应商凭据。当前执行及这些数据库保护限SQLite。

## 原请求恢复与页面归属

相同作用域、相同幂等标识和内容优先返回已提交的原任务，不因当前价格、剩余额度或参考文件后来不可用而再次创建。失去响应后，页面保留原标识和完整内容，用户手动恢复原提交；当前表单选择其他项目或原额度已满，也不改变恢复内容。刷新、离开业务页或换设备后应先查历史，不宣称临时提交记录跨会话持久化。

显式重试固定原费用项目、模型连接、返回格式与参考图证明，需再次确认可能重复费用并新增一次完整预留；原未知费用继续保留。采用不调用模型，也不新增预留。模型调用、重试及采用的确认值必须是实际JSON布尔true。

图片面板以单调递增的页面/身份代次约束读取、上传、提交、恢复、重试和采用；卸载或业务归属改变会销毁自身确认弹窗，旧回调再次执行也会拒绝。托管身份在写入前及接收结果前重新核对当前会话，防止另一标签更换Cookie后沿用旧身份。A→B→A不能恢复旧操作权限。此页面保护不代表身份网关已开放收费：该门禁仍关闭。

## 独立槽位采用

图片槽以身份型空槽意图原子初始化，冲突时读回原槽，不覆盖已有图片。前端按资产和角度共享进行中的初始化，异步返回核对挂载及路由归属。初始化后，不同资产不能借用彼此槽位或候选。

用户采用时先查看当前槽图和时钟，再单独确认 `expected_file_id`、`expected_updated_at`；事务内按原定资产槽执行CAS。确认期间槽位变化返回409。采用只修改该槽的文件、尺寸及格式，保留原文件，不改其他槽或资产主图。不可变FileItem使用 `local-asset-image/` 逻辑前缀、真实扩展名和MIME，通用文件列表不能删除此类任务产物。

资产回跳 `?imageJob=<id>#asset-image-generation` 只读取经归属核对的历史，不生成、重试或采用。任务中心仍只显示通用状态及回跳入口。

## 验证范围

有界本地回归覆盖两种协议、实际参考bytes、顺序用途、跨项目和变化拒绝、不可变SQL约束、费用与取消、显式重试、采用CAS及旧协议兼容。实际浏览器完成上传、3张排序、候选生成、单独采用、满额且响应丢失后的原提交恢复、刷新和配置域名拒绝。独立React/DOM验证与整页浏览器分别记录，不能合计为新后端用例。

URL正向验证使用受控传输边界，没有实际外部CDN下载；真实模型、供应商账单、人物一致性、全部收费身份执行、完整成片和公网部署均未验收。原用户素材及密钥未使用。登记与各次证据见 `capabilities/reference-image-validation.json`；操作步骤见[参考图生成指南](../../guide/reference-image-generation/)。
