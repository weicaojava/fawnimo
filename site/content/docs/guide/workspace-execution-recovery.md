# 原执行的取消、重试与连接变更

任务属于提交时的账号、空间、项目和连接版本。切换账号或空间后先刷新页面，不能用另一个账号的任务链接、请求标识或内部字段继续操作。执行类型仍须由维护者明确开放，项目额度不足时不能新建尝试。

## 响应不明先恢复原请求

先查看原任务历史，使用原请求标识核对已经接受的结果。恢复不是新生成，不应修改提示词、连接、项目或请求标识来“试一次”。已接受记录保留原连接与原提交人；当前连接改变也不能把原任务转交给新连接执行。

本机软件检查实际修改了各自供应商连接，再恢复原连接测试记录，模型HTTP请求数没有增加。新请求不能继续使用旧连接对应的报价上界，必须由维护者重新核对当前连接与真实费用。

## 取消正在执行的任务

明确取消原任务后继续核对状态。已经送达模型服务、但结果或费用仍不明的请求会保留原项目预留；取消意图、浏览器断开或晚到的结果都不等于确认零费用。不能使用另一个账号取消该任务。

本机检查用自己的HTTP服务阻塞一条已到达的请求，再通过真实登录网关取消。晚到字节不会把已取消任务改成成功候选，原请求重放不重复调用；未知额度继续保留，没有实际供应商退款结论。

## 明确确认后重试

失败后的重试是有独立请求标识的新尝试，需要确认可能重复计费并匹配原项目的当前可信报价。未确认、其他账号或项目额度不足时拒绝执行。重复核对同一重试标识返回原尝试，不再调用一次模型；原失败的不明费用不会被新结果覆盖或自动释放。

## 原生视频的暂停与恢复

暂停会停止后续查询或下载，正在处理的一步须先结束；遇到“正在处理”时稍后核对同一任务。恢复只继续原远端任务的查询或下载，不创建新的生成请求。已接受视频的取消也要核对远端状态和费用，不把本地取消意图当作完成退款。

本机检查经过两个真实固定工作进程，执行暂停、恢复和取消，同时拒绝另一个账号的控制请求，生成POST数量和原项目预留没有增加。原生夹具保持远端任务运行态，只证明接受、查询与控制，不证明生成最终视频。

这些检查的模型、媒体、失败响应和报价均为自作本地数据。实际供应商、账单、人物一致性、独立审查及公网验收继续单独记录；费用授权仍为0。
