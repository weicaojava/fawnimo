# 用项目参考图生成资产候选

演员、服装、场景和道具编辑页中的“生成图片候选”支持明确声明的Seedream参考图协议。当前完成的是本地软件流程；真实模型账号、画面质量和外部下载仍未验收。本轮开发没有调用付费模型。固定身份入口的收费门禁仍关闭，配置模型或预算不会打开它。

## 1. 配置图片模型

在模型管理选择图片模型，开启本机单张图片生成，协议选择 `volcengine_seedream_json_v1`。供应商须选择火山引擎（`volcengine`），不能沿用旧文本协议的 `openai` 供应商。实际模型名称只能是以下四项之一：

- `doubao-seedream-5-0-pro-260628`
- `doubao-seedream-5-0-flash-260915`
- `doubao-seedream-4-5-251128`（旧版兼容）
- `doubao-seedream-4-0-250828`（旧版兼容）

模型名称须与受信价格配置一致，不能填写自定义Endpoint ID来替代。保存配置不会测试或生成图片。4.x供应商已列入即将下线范围，实际可用情况须单独确认。

默认选择base64结果，不需要下载域名。如果选择URL结果，操作者必须在模型配置中登记供应商真实使用的确切公共主机，每行一个，最多8个；不要填写 `https://`、端口、路径、通配符、IP或本地域名。下载不带模型密钥或Cookie，不跟随跳转。缺少合法域名时URL选项不可用。

旧 `openai_b64_v1` 模型继续提供单张方图文生图，不支持参考图片或URL结果。请依据模型实际声明选择，不把旧模型当作参考图模型。

## 2. 明确费用项目

先在目标项目的“项目设置 → 项目预算”配置本项目上限，再由操作者按[项目费用配置](../model-project-costs/)登记该模型的 `asset_image` 受信报价。上界需覆盖参考图片及所选尺寸，测试金额不能作为真实供应商报价。

进入资产编辑页，明确选择“费用归属项目”。该选择同时限定可选参考图；全局资产可以被其他项目引用，但本次调用不会自动向其他项目计费。未选项目、缺少受信价格或额度不足时不能提交新生成。

## 3. 选择或上传参考图片

在参考图选择区从这个项目的媒体中选择PNG/JPEG，也可上传新图。最多3张，每张4MiB、总计12MiB；只支持单帧图片，边长15至4096、最多1600万像素，长宽比介于1:16和16:1。上传会新增本项目媒体，不会调用模型。

选择每张图的用途：外观、构图或风格，并用上移/下移调整顺序。提交保存原项目、图片SHA、用途及顺序。服务器会实际解码并校验图片，不接受网页填写的网址或磁盘路径。原文件变化或选到其他项目媒体会拒绝，不能自动忽略参考图继续生成。

选择已声明尺寸：2048×2048、2848×1600或1600×2848，填写提示词和目标槽位。参考图用途属于保存的输入说明，不保证模型一定达到人物一致性或构图要求。

## 4. 确认生成，再决定是否采用

确认弹窗会显示本次项目及完整费用预留。确认后生成一个候选，原槽位图片保持。返回候选后可预览，并检查保存的3张参考图证明、尺寸与用途。

需要替换时，单独点击采用并确认当前槽位内容。确认期间槽位已有别人或另一标签更新，服务器返回冲突，请刷新后重新检查。采用不再次调用模型或预留费用，旧文件继续保留。

切换资产、身份或离开页面会关闭这个页面的确认弹窗。不要把离开页面当作已发送请求的远端取消；查看原任务状态。失败、取消或下载失败都不能证明供应商没有计费。

## 5. 响应丢失时找回原提交

看到“有待确认的原提交”时，使用页面提供的恢复动作并确认原内容。恢复始终使用上次的项目、参考图、模型及请求标识；即使原任务已占满预算或当前表单选了其他项目，也不会创建第二份已接收任务。恢复不是重新生成。

刷新页面、离开业务页或换设备后先查历史；临时待确认列表不保证跨会话保存。确定要再试时使用原历史的显式重试，重新确认可能重复费用。重试继续固定原项目及参考图证明，新建一次预留，旧未知费用仍需核账。

完整协议及下载边界见[图片候选架构](../../architecture/asset-image-generation/)。生成的图片不会自动进入视频参考图或工程ProductionMedia，也不代表视频模型已支持图片条件。
