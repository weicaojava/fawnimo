# 个人工作空间体验与复验

当前新增体验入口是 `http://127.0.0.1:18000/projects`，需在运行该服务的本机访问。原 `http://127.0.0.1:17888/projects` 和 `8000` API 继续保留原本地资料，尚未迁移到新身份空间。这里没有公网平台，B/C完整验收仍在进行。

## 进入个人空间

1. 向维护者安全领取本机测试账号A或B。账号凭据不放在GitHub或公开示例中。
2. 打开18000入口登录，确认顶部显示自己的姓名与个人空间。新账号的个人空间已随账号原子创建，不会获得原本地工程或其他账号资料。
3. 在设置页保存姓名，切换语言或亮暗主题，刷新验证偏好。身份模式下这些设置归用户；空间内的工程设置仍在相应工程中编辑。
4. 如有多个已授权空间，可用顶部空间选择器切换；页面重新加载后再操作。退出使用账户菜单，退出后的旧会话不能继续访问私有数据。

注册默认关闭。维护者明确开启 `--allow-registration` 后，入口才显示创建独立账号；这不代表公网注册与生成额度已经开放。成员邀请、团队管理、账号到期与公网领取策略尚未交付。

## 文字示例及重新建立

当前示例服务、`POST /api/v1/identity/demo` 与项目大厅按钮已实现，本机实际浏览器检查已验证建立、重建、保留旧编辑及双账号访问边界。服务提供纯自作《点亮小岛》文字练习，包含1章、7个待确认镜头、21条首/尾/关键帧提示词，可在现有章节、分镜编辑和工作室入口继续手工编辑。

示例没有图片或视频产物，也没有模型调用。它用于检查制作资料的编辑与持久化，不属于真实模型成片、参考原片或原片还原成果。

“重新建立”会创建全新示例工程，原示例与用户编辑全部保留。一次请求响应中断时，应使用同一个请求标识核对结果；不能为了恢复而另起新标识。成功重放只返回原工程，不将用户后续修改恢复成初始模板。部分创建的内容已被改动或删除时，服务返回409并保留现状，不自动覆盖或重建。每空间最多20次新示例请求，原请求恢复不另占名额。

## 双账号复验

使用两个独立浏览器环境分别登录A/B，避免同一浏览器共享Cookie影响身份。分别创建工程、章节、分镜和上传独立小文件，再刷新读取；B不应获得A的列表、文件、提示词、模型连接或任务。

旧标签仍携带原身份/空间上下文。另一标签切换账号或空间后，原标签提交、读取或使用原媒体链接应得到明确的409提示，再刷新重新进入当前空间。响应中断的生成或示例请求保留原 key，不应被前端自动当作新的请求发送。

以上可用于人工复验。已通过的本机范围包括登记的14类根资源、明确嵌套引用、历史与实际文件字节，详见[资源隔离边界](/docs/architecture/resource-isolation/)。合成失败任务与直接登记的导出历史不代表完整生成/冻结渲染链通过；收费任务的运行中取消/重试、后台执行与候选采用仍待联合验收。逐项状态见[功能总表](/docs/reference/feature-catalog/)，通过门槛见[分阶段计划](/docs/plans/platform-delivery/)。

## 当前可用范围与503提示

新空间可做手工编辑、配置、文件和只读任务查询。持久视频项目独立预算已接入；单独工作室的文本工作流、文本连接测试和单张图片候选已连接项目预留及私有响应证据。视频理解、ASR和原生视频统一账单接线、全部收费隔离与真实账单验收仍未完成。身份网关的收费生成、Agent执行/重试、文本连接测试、理解和相关提交入口继续503；可用性接口也明确显示关闭状态，费用信息仍可读。旧共享执行入口的写入同样拒绝。保存正上限、连接或模板不会启动模型。

登录后进入具体项目，打开“项目设置 → 项目预算”，查看该项目的上限、预留、结算、可用余额和分页明细。未配置时额度为零，所有者可调整，其他角色只读。各项目预算独立，彼此不占额度；系统设置没有预算表单。保存上限不会充值或生成。

提示修订冲突时先刷新核对最新金额，再决定是否修改；输入不会自动重试。待核实的预留不能通过降低上限、取消意图或重复请求清空。明细可分页查看，仅展示当前项目的额度记录。无账单时显示“尚无核对记录”；人工导入后显示已核对金额、待补入金额、授权缺口和未决提示。修改上限不会自动核对账单。操作方法见[人工核对模型账单](/docs/guide/model-billing/)，人工规范化和哈希不代表供应商自动认证。

旧工作空间总额度已归档，不会自动分配到任何项目；预留、已花费0和请求成功也不是供应商账单。真实模型验证需单独明确费用上限，不能沿用此前某次样片预算。当前未通过真实模型质量、完整成片或公网交付。

## 维护者启动与账号交付

身份入口为 `backend/run_controlplane.py`。`--root` 指向专门的私有数据根，`--frontend` 指向前端生产构建，`--probe` 指向受信FFmpeg绝对路径。查看 `python run_controlplane.py --help` 获取实际参数；本机使用回环地址与18000端口，纯HTTP测试需显式 `--insecure-local-cookie`。该参数只允许回环监听，公网部署保持默认Secure Cookie和HTTPS。

离线账号建立使用 `--provision-account` 与一个尚不存在的 `--credential-file`，凭据写入维护者指定的私有文件而不打印密码。该文件应位于公开仓库、构建上下文和共享输出之外；Windows需由维护者核对文件权限。不要把凭据写进本页、Issue或示例工程，也不要为方便领取而共享维护者账号。

旧工作区请继续使用原入口；已有[离线迁移与回退工具](/docs/guide/workspace-migration/)，目前只在私有副本演练，正式入口未切换。不要把旧数据库、media或files直接放入某个新账号目录，固定空间启动器会拒绝非空未认领库。稳定/预览容器方案目前仅静态检查通过，Docker运行与公网仍未验收；用户尚未购买服务器，见 [deploy/workspace/README.md](../../../../deploy/workspace/README.md)。
