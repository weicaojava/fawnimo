---
title: 开放有限体验注册
description: 配置注册名额、有效期和项目数量，并核对用尽及到期行为。
---

先使用新的私有身份网关目录，并构建同源前端。注册默认关闭；原有维护者账号和数据保持原归属。以下 `/srv` 路径为本机私有目录示例，Windows 请替换为自己的私有绝对目录，放在 Git 仓库外。

```sh
cd backend
python run_controlplane.py --root /srv/fawnimo-trial-private --frontend ../front/dist --host 127.0.0.1 --port 18003 --insecure-local-cookie --capacity 4 --allow-registration --registration-capacity 4 --trial-days 7 --trial-project-limit 2
```

这是本机回环体验配置，浏览器访问 `http://127.0.0.1:18003/projects`。正式 HTTPS、稳定/预览隔离及实际公网验收继续按[部署指南](../workspace-container/)执行；本指南不代表已有公网平台。

三个体验选项：

| 选项 | 默认值 | 可用范围 |
| --- | --- | --- |
| `--registration-capacity` | 4 个账号 | 1–128，本轮所有已领取体验账号合计 |
| `--trial-days` | 7 天 | 1–30，仅影响新领取账号 |
| `--trial-project-limit` | 2 个项目 | 1–10，每个体验个人空间同时保留的项目数 |

`--capacity` 是同时运行的工作进程数量，达到时明确返回容量已满，不会驱逐运行中的任务。它与注册名额分别设置；按实际主机资源选择。体验项目数属于资源数量，生成费用仍按各自项目预算核算；收费模型入口继续关闭，已有模型配置不授权本轮费用。

访客点击“创建独立体验账号”，先看到期限和项目数量说明，再填写账号与密码。最后一个名额被领取后，其他访客看到“本轮体验名额已满”，已有账号仍可登录。服务器会原子检查；页面停留较久也不能绕过最新名额。

登录后顶部显示有效期和最多项目数。项目数量已满时，新项目或新示例返回明确提示；可以先删除不需要的项目，再创建新的项目。示例原请求使用原键核对，不重建或覆盖已有项目。

到期后仍可登录、查看和下载资料；项目编辑和新建暂停。页面重新聚焦或每分钟更新提示，后端立即限制新的业务写入。账号资料不会自动删除，名额也不会自动回收；个人外观/语言、退出及切换已授权空间可继续使用。

既有永久账号、CLI 创建的专用账号以及[本机预览资料](../local-releases/)生成的专用账号不会被自动改成体验账号。不要通过改旧用户归属、重置数据库或复制维护者私有目录给注册用户来提供体验。

当前没有公开自动续期或删除接口。变更启动参数只影响之后的新注册，不改已领取者的固定记录。恢复、回切和升级时使用支持体验策略的同版本网关/工作进程，并核对原期限/数量；真实生产回切仍待验。当前实现见[体验生命周期架构](../../architecture/trials/)。
