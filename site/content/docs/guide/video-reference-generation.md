# 为视频选择参考素材与首尾帧

本功能先准备和检查原项目素材。模型配置保存、素材上传、计划锁定和输入摘要都不会生成视频。未授权本次模型费用时，保持生成关闭；已有模型资料不会被自动解密或调用。

## 准备参考输入

1. 在模型管理选择火山Ark视频模型，实际名称为 `doubao-seedance-2-5-260628`。打开“用于原生视频生成”，输入类型明确选择“参考素材、首帧或首尾帧”；原“仅文字”模式继续独立保留。模型连接与完整费用配置见[本机视频配置](../workspace-video-setup/)。
2. 在分镜编辑页完成信息提取确认，回工作室打开“镜头执行计划”，选择本章锁定剧本和固定资产版本。每个镜头展开选择参考方式。
3. “素材参考”可选最多3张图片及1个视频，并用上移/下移决定顺序；“只指定首帧”选一张图；“首帧和尾帧”分别选择两端，可明确选择同一张图。三种方式不能混用，切换会清空此处选择。旧参考列表须明确清除，不会自动删除或忽略。
4. 从原项目选择媒体，或通过“上传到原项目素材”添加后再明确选用。人物/场景版本里的其他图片不会自动变成输入。素材缺失或内容改变时重新核对，不自动换成同名图片。
5. 补全后保存镜头计划并编译锁定。查看“参考输入摘要”，核对项目、镜头、模式、角色与顺序；这里仅核对记录，接受任务前还会实际解码。缺少尾帧时须补全，不能把首帧自动当作尾帧。
6. 有明确费用授权且服务可用时，逐镜提交，核对弹窗中具体项目及本次完整预留。参考生成当前每次一个镜头，项目之间不借额度。
7. 未收到提交响应时点“核对上次视频提交”。它使用原项目、原计划和原请求；即使当前额度已用满或关闭新生成，已经接受时仍返回原任务。不要通过“另生成一个候选”找回旧任务。
8. 接收后先预览候选，再去剪辑页选择并明确采用。采用和刷新不追加模型生成；原已发送费用仍须按真实账单核对。

服务尚未就绪时，已锁定的准备计划可查看“固定输入”；可执行摘要和提交会列出尚缺条件。身份复验或读取失败会保留原提交记录。确需清除本地记录时，先核对项目任务历史，再使用明确的清除按钮；这不会撤销已接受的任务或释放未知费用，之后再生成属于新的费用意图。

## 素材限制

图片为PNG/JPEG，每张≤4 MiB，素材参考图片合计≤12 MiB；实际边长300–4096、最多1600万像素、宽高比0.4–2.5。首帧和尾帧须实际9:16，系统不代为裁切或拉伸。

视频为2–10秒、24/25/30fps、≤32 MiB的MP4，实际H264/HEVC、边长300–1920、像素407696–2073600、宽高比0.4–2.5、连续零点时钟，不能带需旋转或非方形像素的变换。音轨如存在会实际核对并记入输入证明；输出仍请求关闭生成音频，不能据此认定已经配音。

一个新参考计划连同资产来源最多128份不同素材、合计≤64 MiB。文件名、后缀或媒体列表显示成功都不能替代实际内容检查。服务请求固定为4–30整数秒、竖屏480p/MP4、关闭生成音频、保留水印；输出是否合乎创作要求仍由用户检查。

## 管理员配置

价格仍登记在 `native_video`，新参考报价额外填写 `quote.input_protocol` 为 `seedance25_reference_v1`。单次上界须覆盖协议最大3张图片、1个视频和30秒输出，即使当前界面仅选择图片。原文字报价不能直接沿用；原账目与未知预留保持原快照。金额由管理员核对，测试金额不能用作供应商价格。见[模型项目费用](../model-project-costs/)。

视频服务文件可省略 `reference_media_origin` 或设为null，此时使用图片/首尾帧。要加入参考视频，由管理员在已授权独立服务配置准确HTTPS根origin，无路径、查询串或凭据；默认 `/api/v1` 独立工作室保留原交付；固定身份网关另需维护者显式配置准确origin，见[固定身份交付](../workspace-reference-delivery/)。该入口须由原服务按原输入证明只读交付，代理日志不要记录交付查询串。普通网页和导入工程不能提供交付地址。

固定身份worker已增加默认关闭的签名只读交付，仍由原任务核对素材、期限和读取次数；该配置不能开启收费网关。回环HTTP只用于独立自作测试，不代表远程供应商能够访问本机文件；尚无服务器也可以继续本地图片与首尾帧准备。

新参考协议改变执行绑定。旧文字/空报价计划保留，须显式保存新修订并编译，不能直接获得新生成权限。关闭新生成仍可使用未变化原账号查询已封存任务。原理和边界见[参考输入架构](../../architecture/video-reference-inputs/)。

该实现遵循[火山视频任务API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh&redirect=1)的显式角色，采用更窄的本地输入范围；没有把额外供应商或任意媒体格式作为已支持能力。当前软件检查不等于真实模型质量、远程交付、供应商账单、完整收费隔离、成片或公网部署已通过。

万相3.0的图片和首尾帧另走wan30_reference_v1，不接受本页Seedance参考视频；图片须无透明通道，参阅[万相图片输入](../wan-video-generation/)。两种协议各自报价，不自动沿用旧任务或切换供应商。
