# 模型调用的项目费用配置

先在具体项目的“项目设置 → 项目预算”配置本项目上限。此设置只限制项目支出，不会充值、测试连接或调用模型。当前接入范围和身份网关门禁见[模型费用架构](../../architecture/model-accounting/)。

## 操作者配置费用

费用文件由服务器操作者维护，不由网页提交。确认库内模型ID、模型管理中实际用于请求的名称、供应商的历史连接版本、独立账户版本和协议费用上界；报价必须覆盖该协议允许的输入、最大输出或图片尺寸。真实价格、预算授权与模型质量需各自核对，不能使用测试夹具金额作为供应商报价。

单独工作室通过 `MODEL_PRICE_CONFIG` 指定服务器上的绝对文件路径，重启该独立工作室加载。固定身份进程只从自身空间目录 `private/model-prices.json` 加载；不接受请求参数或继承主机价格文件。导入且锁定的空间不会加载费用策略。保持文件私有，不写入密钥或令牌。

下面仅展示格式，默认关闭；所有ID、版本和金额都是自作示例，不能直接用于收费执行：

```json
{
  "schema_version": 1,
  "enabled": false,
  "rules": [{
    "quote": {
      "model_id": "example-model",
      "model_name": "example-request-model-name",
      "provider_id": "example-provider",
      "provider_connection_version": 1,
      "account_version": "example-account-v1",
      "currency": "CNY",
      "max_call_minor": 12,
      "source_note": "示例格式；请替换为已核对的完整上界及依据"
    },
    "kinds": ["agent_text"]
  }]
}
```

`max_call_minor` 使用整数分且必须为正数。`model_id` 是库内ID，`model_name` 必须与模型管理中的实际名称完全一致。`agent_text`、`model_connection_test` 和 `asset_image` 分别登记，可使用不同上界；缺少本协议规则、实际名称或连接版本不符、文件无效时保持关闭。确认实际配置及本次费用授权后才启用。身份网关门禁目前独立关闭，填写价格文件不会开启它。

升级前的报价可能没有 `model_name`。它仍可读取旧记录和核对旧账单，但不再授权新调用；先备份私有价格文件，核对实际模型与费用后补齐名称并重启对应独立服务。不要改写已保存报价、旧账目或未知预留。修改库内模型名称也须重新核对报价，不能靠保留同一ID沿用旧金额。

## 网页确认与后续核对

在 Agent 执行、文本连接测试或资产图片页显式选择“费用归属项目”。页面支持搜索项目并展示已有预留、计入待核对账单后的余额和本次完整预留；没有自动选择第一个项目。Agent按全部LLM节点计算，连接测试使用独立报价，图片一次预留一张。

确认弹窗后服务器再次核对项目余额和完整价格指纹。价格变更须刷新并重新确认。取消未发送任务可释放额度；已发送或结果未知时继续保留。页面失去提交响应时，使用“恢复上次提交”，确认恢复原内容。即使原任务已用满项目额度，或当前表单已选其他项目、修改输入，恢复仍使用上次确认的内容和归属。已接收时返回原任务；未接收时按原授权检查。8项未确认提交会暂停创建更多，先恢复或核对历史。刷新、离开该业务页或换设备后先查询历史，避免把不确定结果当成未提交。

失败或取消的旧任务重试会再次预留，仍归属原项目、原模型连接，旧未知费用继续保留。全局资产当前选中别的费用项目也不会改绑旧任务。生成图片仅产生候选，明确采用才写入槽位；采用不再调用模型或预留费用。

成功结果、tokens、图片候选或供应商请求标识均不等于账单。需要实际费用时使用[人工账单核对](../model-billing/)，保留原证据；未取得匹配证据的费用继续未知。两段调用之间若新账单揭示报价超界或争议，后续预留也会暂停发送，先核对费用。
