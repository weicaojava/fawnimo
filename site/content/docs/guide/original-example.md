# 创建与导出原创示例

登录自己的空间，在项目大厅点击“创建可导出示例”，确认创建。系统会另建《点亮小岛》工程，准备7段原创无声视频、7张图片和28秒剪辑草稿，完成后进入视频编辑。已有工程和编辑会保留。

此流程无需配置模型。运行环境须已开放本地媒体处理并安装维护者配置的FFmpeg；未开放时页面会保留原请求，已有文字示例仍可继续编辑。

## 编辑与导出

1. 在时间线中展开镜头，预览素材，按需修改剪辑标题或裁剪区间。示例没有对白、音乐或源音轨。
2. 展开“逐条人工内容保留标记”，检查每条剧情对应的镜头与时间段。确认前标记保持未勾选，锁定按钮不可用；这些标记只代表你的声明。
3. 点击“保存剪辑草稿”。已保存输入满足要求后，点击“锁定时间线版本”并确认。
4. 在“历史版本与本地导出”中点击“导出此锁定版本”。完成后分别下载MP4视频、SRT字幕、VTT字幕与来源ZIP包。

导出视频为360×640、30fps；本例未裁剪时为28秒，导出音轨保持静音。SRT为空，VTT只有格式头，均符合本例没有对白的输入。ZIP包含视频、两种字幕和来源清单，不包含私有存储路径。

字幕为单独文件。更改草稿后需要再次保存、锁定，再为新版本导出；旧版本与旧文件保留。项目也可从章节或工作台再次进入视频编辑。

## 中断、恢复与重新创建

网络中断或页面提示结果尚未确认时，回项目大厅点击“核对上次可导出示例”。系统沿用原请求，找回已经完成的工程。切换账号或空间时先刷新；回到原账号仍能继续核对自己的原请求。

恢复会保留后来修改的标题与采用选择。原素材被删除或改变时会提示冲突，不会自动生成另一份素材盖过原内容。若空间正在处理另一个示例，请稍后核对同一请求。

要建立另一份示例，等原请求确认完成后再次点击“创建可导出示例”。新示例使用新工程，旧示例保留。文字与可导出示例共用每空间20次新请求上限；恢复同一请求不新增名额。项目费用预算仍按单个项目管理。

“创建文字分镜示例”保留原来的文字练习：7个待确认镜头和21条提示词，可以编辑分镜准备内容。

## 素材来源与验收范围

几何小岛、光点、方块与三角形由本项目代码绘制，未使用用户原片或第三方素材；作品源码按仓库 Apache-2.0 许可提供。创建、剪辑和本地导出均不调用模型。

完成导出说明软件流程可用。剧情、画面表现、语义、口型或配音质量需另行审查；本示例不会把这些资格自动标成通过。当前实现见[架构说明](/docs/architecture/original-example/)，公网和真实模型状态见[功能总表](/docs/reference/feature-catalog/)。
