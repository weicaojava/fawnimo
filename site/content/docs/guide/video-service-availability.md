title: 视频服务可用性
---

OpenAI 官方已在2026-09-24停止 Videos API 与 Sora 视频模型，见[官方弃用公告](https://developers.openai.com/api/docs/deprecations)。填写新的密钥或重复发送不会恢复这个接口。

遇到“官方视频接口停止服务”时，在模型设置中明确选择本项目已经声明支持的视频供应商和协议，再检查该空间的连接、报价及项目预算。当前托管视频执行仍按声明的Seedance档案准入，维护者开关默认关闭。不会自动换供应商、模型或使用其他项目额度。

已有配置、视频文件与历史记录保留。远程旧视频查询也不能恢复已停止的官方接口；已经保存的本地文件仍走原下载与权限流程。单独填写的其他兼容地址只保留原驱动，并不代表其参数、模型质量或真实账单已经验收。

软件验证使用自作数据：69项相关检查通过，含20项新退役检查；旧调用链仍按原409停用契约拒绝。没有调用真实供应商或使用原用户密钥，本轮费用0。
