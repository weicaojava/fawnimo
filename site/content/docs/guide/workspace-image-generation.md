# 身份空间图片生成准入

这是维护者控制的图片执行开关。费用始终属于所选项目，没有整个工作空间的合计预算。保存连接、调整项目预算、创建账号或查看可用性都不会自动打开此开关。

## 开放前准备

1. 确认账号、成员写权限和所属空间，使用身份服务返回的真实空间ID，不使用项目ID或浏览器任意填写的值。
2. 为该空间核对独立图片服务、明确声明的模型协议和准确连接版本；维护者在该空间自己的`private/model-prices.json`登记真实单次费用上界。测试报价不是实际价格，不复制其他空间的私有文件。
3. 到原项目设置本项目预算，默认额度仍为0。迁入旧工作空间的执行锁继续保留，此开关不能解锁旧队列、加载旧报价或继承主机密钥。
4. 只有另获授权后才能验证真实模型和费用。仓库自作HTTP/图片回归不构成费用授权，本轮没有调用真实供应商。

## 明确列入空间

网关只在启动时读取`--root`对应数据根的固定文件`private/asset-image-admission.json`。参考`backend/workspace-image-admission.example.json`，默认内容为：

```json
{
  "profile": "workspace_asset_image_admission_v1",
  "schema_version": 1,
  "enabled": false,
  "workspace_ids": []
}
```

维护者确认后才将`enabled`设为true，并将实际需要开放的空间ID填入数组，再重启自己管理的网关。最多16个不同ID，格式为`ws_`后32位小写十六进制。空名单不开放任何空间；缺文件、禁用、重复字段、未知字段、错误ID、超过16KiB或路径重定向均保持关闭。配置不包含金额、凭据、网址或工作进程地址，不由浏览器上传。

开关只覆盖独立资产图片流程中演员、服装、场景、道具槽位的新任务和显式重试。其他收费协议、回调及旧共享生成写入口继续关闭；查看者和已到期只读账号不能提交。底层模型服务、报价和项目额度也必须分别就绪。

## 页面生成与原请求核对

登录后进入相应资产编辑页的“生成图片候选”，明确选择已登记费用的图片模型和原项目，可按受支持协议选择该项目参考图。核对提示词、输入顺序和画幅，再确认预留。候选不会自动替换槽位；查看当前图片后另行确认采用，采用不会再次预留。

参考校验繁忙或响应不明时使用原请求标识核对，不改成新标识盲目重发。原页面的“恢复上次提交”只属于仍挂载的页面；离开前先核对，刷新后查看服务器任务历史。失败、取消、不明结果及实际账单继续沿用原项目费用规则。

## 暂停后核对

修改或移除准入文件会关闭新提交；更改空白也须重启网关才能使用新的策略。恢复文件为启动时相同字节会恢复原策略，因此维护期间应保存明确禁用配置并在合适时间重启。已有任务不会因此自动取消，历史、下载和已预留费用仍保留。暂停不等于释放不明调用额度；先核对原记录和账单。

软件验证覆盖两个真实身份工作进程、各自自作图片HTTP源及完整编译页面17项检查。相关359项通过、1项平台跳过，新增40项全通过；尚无真实供应商、实际账单、全部收费协议联合或公网通过结论。
