---
title: "运行按账号隔离的本机模型模拟"
description: "维护者配置自己的自作协议服务，保持正式费用与原工作区独立。"
---

1. 在独立测试根建立账号和新空间，保留已有工作区。先让worker完成固定身份标记；未领取的旧数据库及迁移锁定空间不能用本配置执行。
2. 由维护者在该空间的private目录保存local-models.json，使用服务器给该空间生成的完整workspace_id。配置默认关闭；端口只填写自己实际运行的自作服务。

```json
{"schema_version":1,"workspace_id":"ws_00000000000000000000000000000000","enabled":false,"agent_text_ports":[19001],"asset_image_ports":[19002],"video_understanding_ports":[19003],"native_video_port":19004}
```

3. 示例零ID必须替换为实际空间ID。启用后，模型连接只对对应协议的127.0.0.1端口提供本机例外；不在本空间相应协议组明确列出的端口不获本机例外，localhost也不匹配。仍需在模型库保存专用自作连接、协议标志和独立受信价格，并为具体项目配置预算。模拟金额不是供应商报价或本轮费用授权。
4. 在维护者拥有的隔离服务生命周期内重启对应测试worker加载配置。公开平台的收费提交仍503；本配置的正向验收由维护者私有测试通道完成，不向浏览器发放worker token。项目页面继续核对已保存的任务、候选和原项目费用。
5. 保留原请求标识核对丢失响应，取消或停服务后未知预留仍需查账；已有成功不能自动重发。要结束回归，关闭配置并按拥有关系停止测试服务，保留账单及来源记录。

完整软件范围和实际输入边界见[架构](../../architecture/workspace-local-models/)。真实供应商、模型质量与MP4输出、完整公网流程分别验收；当前本轮实际费用授权为0。
