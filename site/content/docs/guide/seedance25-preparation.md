---
title: 不付费准备 Seedance 2.5 镜头请求
---

按既有环境说明安装依赖并备份数据库/媒体，在backend目录运行`uv run python migrate_video_dna.py`，再运行`uv run python run_local.py`。默认启动提供禁执行的S25A准备档案，不读取或启用密钥。

1. 在制作剧本页准备剧情、人物、场景及实际镜头映射，发布准备快照。当前每镜必须为4–30整数秒。
2. 在分镜编辑页完成信息确认，然后进入本章工作室，打开“镜头执行计划”。
3. 新建或打开草稿，选择制作剧本准备快照，点击“使用此准备模型”。核对准备档案的固定参数和未验证提示。
4. 为每镜选择对应人物与场景的固定版本。此切片不接收参考素材；选定版本自带媒体也会阻断，不会被自动忽略。可保存不完整草稿，按具体缺项处理。
5. 保存后“编译并锁定计划”，查看“实际请求预览”，检查逐镜模型、时长、文字和输出参数，可下载惰性JSON。下载不会执行生成或预留费用。
6. 修改后先保存并编译新版本。旧计划仍保留，失配或绑定不同的历史计划没有当前wire body；不要把它当成已经发送的请求。

默认所有付费提交不可用，直接调用提交API也不会创建任务或预算预留。模型管理的测试入口目前明确标记未验证，不能据此宣布账号或模型已通过。

服务限流会暂停原任务，要求等待结束后再显式恢复。无需重复创建任务或更换恢复标识。密钥只通过本地私密配置管理，不放入剧情、提示词、DNA、计划JSON或导出包。
