# 身份空间的执行类型准入

此开关控制指定身份空间可以提交哪些独立执行流程。默认全部关闭。它不设置金额，不给工作空间新增总预算，也不替代模型连接、维护者报价、项目额度或提交前确认。

## 选择类型与空间

网关只在启动时读取`--root`数据根下的固定文件`private/execution-admission.json`，默认参考`backend/workspace-execution-admission.example.json`：

```json
{
  "profile": "workspace_execution_admission_v1",
  "schema_version": 1,
  "enabled": false,
  "workspace_ids": [],
  "operations": []
}
```

维护者确认后才将`enabled`设为true，列入真实身份空间ID和需要开放的类型，再重启自己管理的网关。同一文件列出的空间使用同一组类型，最多16个不同空间；ID为`ws_`后32位小写十六进制。空空间或类型名单均不开放任何调用，不接受通配符、重复项、网址、凭据、金额或客户端上传的配置。

| 类型 | 覆盖的明确提交 |
| --- | --- |
| `agent_execution` | 独立文字工作流、单模型连接测试，以及显式的新尝试；连接测试也需要原项目费用确认。 |
| `script_preparation` | 原项目原章节的剧本候选准备；结果仍须审阅后明确采用。 |
| `video_understanding` | 原项目视频理解和显式重试；视觉、ASR分别按原报价计入同一项目。 |
| `native_video` | 原项目的独立视频提交和镜头计划提交；当前已声明的固定协议继续受原素材与连接条件限制。 |

图片不在此名单内，仍使用独立的[图片生成准入](/docs/guide/workspace-image-generation/)。这些开关都不会开放回调和旧共享生成写入口，不会给查看者、已到期只读账号或未列入的空间增加权限。

## 核对原项目与连接

各空间只使用自己的固定数据库、文件、模型连接和维护者报价。先核对明确支持的协议、准确连接版本及实际费用上界，再在所选项目设置预算；默认项目额度为0。选择模型、保存设置或增加预算都不会自动开放执行。

迁入旧空间继续保持执行锁，不加载旧报价、原生服务或本机端口；此开关不能解锁旧队列或继承主机密钥。开发测试使用的本地响应和金额不是真实供应商报价，也不构成实际费用授权。

页面提交前仍需明确确认。后台固化原用户、项目、模型连接和请求标识；切换账号或空间后，旧页面必须刷新核对。原请求结果不明时使用原标识恢复或查看历史，不将它换成新标识盲目重发。显式重试是另一次有费用上界的新尝试，未知费用仍按原项目规则保留。

## 暂停与恢复

修改或移除准入文件会关闭新的执行提交；修改空白也属于变化。新的策略必须通过重启网关加载，已有任务和预留额度不会自动取消或释放，历史仍可查询。

若将文件恢复成启动时完全相同的字节，会恢复原策略。需要持续暂停时，保存明确禁用的配置，再在适当时间重启网关。取消、重试和账单核对仍针对原任务，不能把暂停开关当作退款或账单确认。

## 软件验证范围

本机以两个真实固定工作进程、各自自作HTTP模型源和刻意相同的业务ID验证：文字、连接测试、两步剧本候选、图片、原视频ASR/视觉和原生视频接受/查询；同时检查原请求重放、原提交人、项目预留、跨账号拒绝、查看者/未列入账号拒绝、策略暂停和项目满额拒绝。
