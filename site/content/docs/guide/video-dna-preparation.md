---
title: Video DNA 人工复核与复现准备
---

先按项目既有依赖说明准备环境，备份所配置的数据库和媒体。在backend目录运行`uv run python migrate_video_dna.py`完成增量升级，再运行`uv run python run_local.py`启动本地API。前端按front/README的现有方式启动。迁移不会替你配置模型账号。

在现有视频逆向页先确认原片切点，再打开Video DNA工作区。模板按原始解码帧划分镜头，保留角色、场景、道具以及构图、相机、光影、动作、连续性、声音和对白字段。没有观察到的内容以有原因的未知保存，系统不会自动翻译或补造原作者参数。

每条非未知声明需要中英文、人工置信度及实际原帧证据。推断还需要说明理由。无声轨不能标记观察到的声音或非未知对白；音效构想只能作为明确推断。人工复核与置信度并不代表视觉识别、ASR、内容或口型质量已通过。

草稿保存采用修订保护。锁定前需要完整原确认镜头集合、标题和复核人；可保留明确未知。角色等分析身份不会复制成生产实体；可人工对应本工程一个精确生产版本并说明，锁定时核对版本与所有引用媒体。

原分析确认切点改变后，旧草稿保留来源，需要从当前分析新建并迁移内容。历史快照始终可读取、下载与比较，不被新切点改写；原片或参考媒体损坏会单独显示不可用。JSON导入只创建新草稿，外部通过状态、任务或评分不能变成系统资格。

七层复现准备清单是人工重建假设，不能直接执行生成。原R1没有记录可靠末帧结束时间，最后镜头结束用帧N哨兵表示，精确结束时间和时长仍未知。后续真实重建必须另验模型能力、尾长和完整质量；本页不会自动提交模型、扣额度或采用片段。

锁定后选择确切历史快照，读取并下载七层准备清单；选择两份快照可查看变更及受影响镜头。只改一个角色的服装时，检查影响是否仅落在该角色的引用镜头。下载的快照重新导入会成为独立草稿，原快照保持不变；相同正文再次锁定的内容hash和准备hash应相同，新快照ID仍不同。

目前导入只支持版本1，完整文件不得超过2MiB，字段数值使用整数。未知字段填写原因；未映射的生产角色、场景或道具版本会显示待处理事项，不能据此进入真实执行。完整准备清单超限时应减少输入或拆分工程后重新复核，不会静默删去内容。
