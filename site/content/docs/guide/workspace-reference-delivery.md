# 配置固定身份参考视频交付

这是维护者的可选配置。默认关闭；启用只接通素材读取链路，当前身份网关的生成提交仍返回503。没有服务器时可继续本地开发和输入准备，不需要购买资源或调用付费模型。

## 配置前核对

- 使用本版本网关及匹配的固定工作进程，私有数据根与前端构建目录彼此独立、互不包含。
- 交付地址使用自己控制的准确HTTPS根origin，与网关 `--public-origin` 完全相同，无路径、查询串或凭据。
- 模型仍须另有明确管理配置、完整参考协议报价、项目预算和调用授权；交付开关不授予这些权限。

维护者启动参数示例，路径和域名须替换为自己的值：

```text
python run_controlplane.py --root <私有身份数据根> --frontend <独立前端构建目录> --probe <受信FFmpeg绝对路径> --public-origin https://studio.example.com --reference-media-origin https://studio.example.com
```

本机自作测试可在回环监听上显式使用 `--insecure-local-cookie`，两个origin同时填写相同的 `http://127.0.0.1:<端口>`。这是本地测试例外，不能据此认定远端模型可访问本机；容器默认启动也不会自动加此配置。

模型服务配置中的 `reference_media_origin` 必须填写同一个origin。省略或设为null时，保留图片和首尾帧模式。已有原协议计划不能直接当成新交付协议运行，应重新核对、保存明确修订并编译。输入限制与计划步骤见[参考生成指南](../video-reference-generation/)。

## 密钥和备份

首次启用会在私有身份根创建 `.reference-delivery.key`。不要放入前端目录、公开仓库、构建上下文或共享下载目录；维护者也不应复制给模型服务。停止同一根的网关和工作进程后，使用[全根离线备份与新路径恢复](../local-releases/)保存配套身份库、空间与密钥，不要只复制一份业务数据库。

已有密钥错误时启动会拒绝，不能靠删除文件自动修复。替换密钥会使旧链接失效，现有工作进程的配置也不能在线悄悄切换；先停止服务，再由维护者核对历史任务和恢复材料。Windows请核对私有目录权限，POSIX由启动检查文件或根目录的私有权限。恢复副本和备份包都可能含模型凭据，只在私有位置保存。

## 读取结果

链接只对应原项目的一份已核对视频，一小时有效，GET/HEAD合计最多16次读取。素材变动、原任务不再可读、过期或签名不匹配会404；并行读取用满会429。不能把Cookie、另一个账号或另一个空间ID加到链接中恢复权限。响应丢失后核对原任务，不要为读取失败另起生成请求；未知预留保持在原项目。

网关已避免在自身访问日志中保留交付查询串；维护者仍需让前置代理和接收方避免记录完整链接。不要把链接发到Issue、公共日志或聊天。

已通过的是自作服务和独立新数据的本地软件验证。真实供应商取素材、真实模型费用、画面质量、完整成片、独立审核和公网部署尚未通过；本轮模型费用授权为0。权限原理见[固定身份交付架构](../../architecture/workspace-reference-delivery/)。
