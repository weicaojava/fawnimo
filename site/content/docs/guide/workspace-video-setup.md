# 配置本机视频生成

本地手工编辑、原片技术分析、资产管理不需要启用视频模型。以下步骤只在准备进行真实视频调用时使用；本轮软件验收没有执行这些收费调用。

1. 在工程“资产版本 → 执行任务 → 视频服务配置”下载配置模板，保存到本机私有配置目录。保持 `enabled=false` 时不会启动视频执行。
2. 在本机设置模板 `credential_env` 指定的专用环境变量，默认名为 `JELLYFISH_VIDEO_API_KEY`。凭据不要写进模板、提示词、项目导出或聊天。若更换账号或配置，需要同时更新独立的 `account_version` / `service_version`，避免旧任务身份混用。
3. 先核对当前模型、输出规格与计费方式，填写整数分 `quote_minor` 及 `quote_note`。它是单次请求的受信预留值，不是系统自动查询的实际账单。未经核对的报价保留空值，此时系统不会开放提交。
4. 在确定要启用时才将模板 `enabled` 改为 `true`。启动 `backend/run_workspace.py` 时显式传 `--video-config <绝对配置路径>`；也可以由启动环境提供 `VIDEO_RUNTIME_CONFIG`。已有进程不会自动热切换密钥、服务或预算策略；需要先关闭本机已确认的旧服务再按原工作区路径启动。不要删除或替换 `work/local-studio/`。
5. 在网页刷新服务状态，在“项目设置 → 项目预算”为目标项目保存独立累计上限。保存预算不生成视频。到分镜工作室补齐镜头准备，保存并重新编译绑定当前服务的新计划，核对提示词、时长、能力与费用后逐镜提交。
6. 结果先进入候选；在剪辑页明确采用后再进入时间线。失败、取消或就绪都不能直接视为退款或费用结清。提交结果未知时核对原任务，不能通过新请求标识重复生成。

本配置当前仅支持页面列出的文本生成规格，不接人物参考图或音轨。若计划包含参考媒体，会明确阻断；请使用支持该能力且经过验证的适配，不要删除来源信息来绕过检查。

当前实现与边界见[本机视频生成配置与工程预算](/docs/architecture/workspace-video-runtime/)。
