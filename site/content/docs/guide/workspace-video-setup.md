# 配置本机视频生成

手工编辑与本地素材工作不需要开启视频模型。操作者明确确认本次费用授权前保持关闭；下面说明核对真实费用后的安装步骤，不代表已经生成或验收真实模型。

1. 在模型管理创建本空间供应商与视频模型，标记“用于原生视频生成”。当前受限模型名为 `doubao-seedance-2-5-260628`，供应商为支持此固定档案的火山Ark；保存开关不会发请求。凭据只保存在本空间私有连接配置，不放在聊天、提示词或导出文件。
2. 管理员在受信 `model-prices.json` 为该库内模型明确登记 `native_video`、实际名称、供应商ID/连接版本、独立账户版本、覆盖最大输入/30秒固定规格的单次整数分上界和依据。不是系统查询的真实账单，禁止照抄自作测试金额。格式见[模型项目费用](../model-project-costs/)。
3. 在项目的执行任务区展开“视频服务配置”，选择模板使用的模型并下载关闭模板。保留 `enabled=false`，填入所选model_id和独立service_version。旧credential_env/account_version/quote_minor/quote_note可供历史读取，当前应用不以它们授权新请求，不要填写key、端点或CDN覆盖。
4. 单独工作室由操作者用绝对 `--video-config` / `VIDEO_RUNTIME_CONFIG` 及 `MODEL_PRICE_CONFIG` 安装配置，确认费用后才启用并重启该服务。固定身份进程仅加载自身已认领、未导入空间的 `private/native-video.json` 与 `private/model-prices.json`；填写它们不会打开身份收费网关。不要停止、删除或替换原工作区及用户资料。关闭新生成仍可使用未变化原账号查询已有封存任务。
5. 在本项目“项目设置→项目预算”保存独立上限，回工作室完成准备、保存并重新编译匹配当前服务的新计划。确认具体项目和完整预留后逐镜提交；项目之间不能借额度。
6. 未收到提交响应时点“核对上次视频提交”。它复用原项目、计划、镜头、确认和请求，刷新、表单有编辑、额度用满或关闭新生成后仍可核对；原记录已接受时返回同一任务。另生成候选会新增一次完整预留，旧未知费用继续保留。
7. 接收的文件先是候选，剪辑页明确采用才进入时间线。ready、失败、取消或请求ID不等于结清费用；需要账单时使用[人工规范化对账](../model-billing/)。只有未发送取消或明确匹配的账单证据才能释放费用。原生取消当前只查询服务是否已cancelled，不发删除请求。

固定文字生成档案为4至30整数秒、9:16/480p/MP4、无生成音频并保留水印。首尾帧、图像/视频/音频参考及更多供应商另验，不要删来源或转换素材绕过能力检查。已有加密模型资料不会自动解密、复制给新空间或回填旧任务授权。

实现边界见[视频运行时](../../architecture/workspace-video-runtime/)及[共同项目账单](../../architecture/model-accounting/)。两个本地项目的测试不代表收费双身份隔离；模型质量、完整成片与公网资格仍待验。
